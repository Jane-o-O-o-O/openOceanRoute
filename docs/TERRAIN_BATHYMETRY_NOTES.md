# 地形来源库到二维动力海底

`POST /api/terrain/bathymetry` 真实查询已声明的共享地形来源；不把一维剖面横向铺成测深，不推断变深施工初态。

```json
{"project":{"...":"完整schema1工程及terrain_sources"},"config":{"origin":[118,22],"bounds_m":[-40,-40,40,40],"nx":5,"ny":5,"vertical_datum":"明确测深基准","sea_surface_height_m":1.25}}
```

origin是WGS84模型初始船位；X/Y为该点中心的局部AEQD投影米制坐标。bounds_m为[xmin,ymin,xmax,ymax]，必须覆盖[0,0]；各值±100,000m内，网格间距至少.001m，nx/ny为2–1000整数且总节点最多10,000。纬度绝对值>=89°暂拒绝。查询把每个真实网格节点反投影到WGS84，再按库优先级和明确的垂直基准采样，不能自动减少节点满足预算。

海面高度h必须由用户明确给出，单位米，以选用源垂直基准为零向上为正；不允许省略而默认为0。源水深d向下为正，源高程为-d；模型高程为 `z_model=-d-h`。这只作明确的垂直平移，不执行潮汐、海图/大地高或其它基准变换。h范围±100m。选择不存在的同名基准时全NoData，不自动采用另一来源。

结果提供完整 `seabed_grid`（见 `BATHYMETRY_NOTES.md`），行对应升序Y、列对应升序X，源CRS为AEQD米制、投影原点[0,0]。source.sha256声明来源库摘要；derivation.grid_sha256另校验完整网格文档，两者意义不同。derivation保存源基准、h、位移公式、库/路线摘要、原点、源方法声明、实际预算与有效/缺测/回退计数。samples保留每节点WGS84位置、行列、水深/模型高程、来源fingerprint及回退；不会返回虚构的测量精度。

任何缺测保持null。节点全部水深不代表所有接触单元已知；动态法向需四角已知。接口构造机械高度场并检查原点单元，成功时can_apply=true；无法形成已知单元、原点缺测、正/零高程、超深/过陡时仍返回真实网格，但can_apply=false与实际错误。不能为“可运行”填零、限坡或截深。该检查没有证明未来所有缆/船轨迹覆盖，运行中出域/缺角会明确拒绝。

query_config仅允许max_work_units与max_output_bytes预算，沿用多源实际逻辑预处理/点查询计数和输出体积检查；预算不足不返回部分成功网格。源码接口不会修改工程；界面输入或项目改变后应重生成。可下载网格单独用于动态设置，也可下载完整转换结果保留追溯。动态模型的初始投影、速度级摩擦、点接触、网格上限及未验收精度仍全部适用。ShipPlan到连续任务的自动预备窗口保留定深平床限制；本接口不自动解除该限制。

真实测试覆盖25个来源节点及投影/高程、孔洞回退/NoData、明确基准筛选、预算拒绝、真实生成网格进入动力求解和新检查点。无原厂、海试或测深控制点的精度对照。
