# 共享 GIS 图层叠放与不透明度

MakaiPlan 产品说明第4页及官方规划网页明确说明调整图层顺序、透明度和显隐。本次增加实际编辑与渲染，不改变海缆几何、海图测深值或制造库存。

图层数组由底向上绘制，资源面板由上向下显示，因此面板首项覆盖末项。上下移动改变共享 `layers` 数组的实际顺序，显隐使用 `visible`，合法旧图层缺省为可见，与后端投影合同一致；读取和保存不擅自填写原字段。`display.opacity` 是0至1的不透明度，1保留原描边和填色强度，0表示视觉透明；未声明或不可用显示值按1呈现，原文件内容不会被自动改写。移除保留现有操作，可以撤销。

经纬地图将同一图层所有实际Leaflet SVG路径归入一个合成组后统一应用该不透明度，线/点与面保留原默认描边/填色强度；同层重叠不会重复叠加不透明度。重绘时同时清理旧路径及合成组，交互事件仍保留在实际路径；可定位全部可见GIS几何。投影视图对实际SVG组应用不透明度，并按照当前共享数组排序。仅叠放或不透明度修改不重算已通过的投影，也不改变已有投影坐标；输入几何、显隐或坐标系变化仍使旧投影失效，须按既有流程重新计算。多边形孔洞保持SVG `evenodd` 与原始坐标。

修改通过完整工作区草稿、共享资源校验、撤销/重做及保存/修订处理。`source`及其他扩展字段保留，不从图层显示值生成工程水深，也不把不可见图层从计算规则中擅自删除。真正删除图层是明确的资源操作。

浏览器独立验收位于 `web/tests/layer-display.spec.ts`，使用显式合成孔洞图层及真实后端API，检查实际Leaflet/SVG属性和叠放、投影不重算、几何及库存不变、来源持久保存与重新打开，以及显隐/删除撤销。正式执行记录须另存，测试建议本身不代表通过。
