# 非零稳恒海流定端初态：独立数学与恢复验收

2026-10-04，未发行的开发阶段记录。本文与新 [独立测试](../tests/test_current_initial_review.py) 描述当前受限研究模型的实际验收，不修改冻结0.6产品，也不证明Makai原厂算法、现场张力精度或完整软件等效。此前 [稳恒流范围提案](STEADY_CURRENT_INITIAL_SCOPE.md) 是实施前推导；本记录只为下述真实运行行为提供证据。

## 独立受力基准

预期值不调用被测水动力、材料或初态求解helper。材料覆盖用60位Decimal对每个自然元素与声明区间作交集积分；得到湿重、干质量、附加质量、柔度和Cd×直径积分。每元素缆载荷各一半分给两个节点，零长度点实体按真实自然制造站的线性系数α分配。

```text
C_i = integral(1/EA) ds             [m/N]
T_i = max(chord_i-rest_i,0)/C_i     [N]
Kc_j = rho/2 * half(integral Cd*d ds)       [kg/m]
Kb_j = rho/2 * sum(alpha_b,j*Cd_b*area_b)   [kg/m]
tau_j = index-secant(p)_j / norm(index-secant(p)_j)
u_j = U(p_j)-v_j
Dc_j = Kc_j * norm((I-tau*tau^T)*u_j) * (I-tau*tau^T)*u_j
Db_j = Kb_j * norm(u_j) * u_j
F_j = F_axial,j-W_j*e_z+Dc_j+Db_j
```

深度流表替换主恒流，按max(−z,0)分量线性插值，区间外保持端值。节点切向使用节点索引secant，不以不均匀自然段长重新加权。非零水平流会产生竖向缆拖曳；点阻力在各分配节点取实际流速，不在显示实体位置先求一股阻力。恒流下两种point算法恰好一致，剪切流下独立反例明确不同。

负点湿重保留向上的符号；干质量与等效惯性质量分别积分，不能以质量乘重力代替净湿重。自由节点满足F+Nn=0；固定端反力为−F，包含端半缆湿重、点载荷与真实端拖曳，不能替代首末段张力。法向支持N为单侧非负量；本次静力没有切向粘着历史。

## 不同坐标下构造参考

离床参考由独立的**段牵引递推**构造，而不是复制被测位置/接触求解器。给定固定最老端牵引、自然段和材料柔度，令朝船的段牵引为f_i：

```text
p_(i+1) = p_i-(rest_i+norm(f_i)*C_i)*f_i/norm(f_i)
f_(j-1)-f_j-W_j*e_z+Dc_j(p)+Db_j(p)=0
```

参考构造器在牵引变量中解该非线性递推，然后把所得两端坐标作为真正固定边界交给产品；产品仍自行优化并重新验收。非零O=37m、自然段[12,2,3,1,4,2,3]共27m，材料边界穿过元素，w、EA、Cd和直径不同，并包含−25N非节点浮力点。制造船端站为64m，初始新增放缆为0。

恒流(0.32,−0.27)m/s参考最大缆拖曳11.50N、竖向3.29N；剪切流从(0.2,−0.15)变化到(0.55,0.25)m/s，最大竖向拖曳1.73N。独立构造自由节点残力分别约1.11e−11N与9.07e−12N；真实产品候选独立复核分别约6.33e−11N与9.01e−12N。这些是特定合成输入，不是通用精度界限。

接触参考增加真正法向反力未知量，并将床面法向纳入牵引递推。使用完整双线性曲床

```text
z = -6.266203064885079 + 0.01*x + 0.015*y + 0.0003*x*y
```

不是拟合平面或挤出一维剖面。参考一个自由接触节点N≈4.480220774727765N，固定锚真实离床。实际候选独立残力约1.10e−11N。另将节点初值横向和竖向扰动：初始自由节点最大残力约110.66N，真实求解用了9次Jacobian、172次函数评估，最终残力约1.28e−11N，与独立参考最大位置差约2.66e−15m。该例证明实际优化，不能由一份正确seed直接通过来替代。

每条真实直弦的床隙在上述床上都是二次多项式；独立验收端点与合法内部极小值。另有节点全部离床超过10m、非零流受力恰平衡，而弦中间穿真实窄床脊0.2m的反例，实际明确拒绝。节点/残力合格不能绕过全弦覆盖。NoData也明确拒绝，不填零或延伸床面。

## 首步与方向质量矩阵

新model-v5是明确的方向质量矩阵分裂积分器，不称标量XPBD或完整非线性隐式流固求解。旧状态的切向与拖曳大小固定到本步，令B=AcP+AbI、A=MI+hB。独立dense3×3求解验证实际预测器与A逆一致；自由节点A正定。新力预测已经加入旧轴力、湿重和实际法向支持，warm乘子仅承载后续约束增量，不能再次施加旧力。

实际恒流/剪切平衡在h=0.008、0.004、0.002s多步中均核对位置、速度、Hooke力和库存，未借助节点锁定或冷起settling。固定船与零放缆的参考位置变化在上述精确离床例约0—1.8e−15m；测试位置阈值1e−7m、速度1e−6m/s、独立节点力1e−6N。非零船动和放缆产生真正自由节点响应，0.08s新增0.02m，原27m库存不再次投入。

另有共流速度、零拖曳和水平90°旋转协变的实际矩阵/动态检查。新显式raw2在零流下仍为v5/schema4，真实旧raw1仍为v4/schema3；零流对照不替代非零流验收。

## 历史流、恢复与容量

实际入口是现有prepare-equilibrium-initial与dynamic，raw `oceanroute.dynamic.initial-equilibrium.v2`明确包含canonical `initial_fluid`。完整rho、主水平流、深度表、深度约定和端值保持政策被冻结；fresh必须匹配实际主配置。provenance.v3保存完整材料证明、逐节点U/切向/Kc/Kb/缆和点拖曳及外力，model-v5配checkpoint schema4。历史流只从原raw复核；合法future current/profile override产生新的真实瞬态，不改写原始proof、不重新优化或再次投入库存。

独立JSON/HTTP验收实际预备、启动、保存、关闭任务owner、重新打开SQLite、创建续算子任务，与一次性真实运行比较位置、速度、自然量、质量、湿重、EA和新增放缆。初态只首块优化，恢复实际收取证明校核工作。真实冻结0.6 wheel生成的两份v1/schema3中途JSON继续以v4恢复，即使未来流非零也不自动升级v5。

重签checksum后的原流、密度、Cd、节点U/拖曳/外力、proof摘要、scheme降级或当前质量错误均拒绝。更强反例同时更新raw历史流、request摘要及逐节点水动力字段，仍因原节点不满足真实新流受力而拒绝。checksum只检测一致性，不是可信认证，也不声称追踪所有任意新构造的动态历史。

工作预算按4NF、实际Jacobian和全部位置有限差分评估计账，不暗增默认上限。25次函数评估的坏seed实际耗尽后不返回可应用平衡；1工作单位预检在优化前拒绝。实际UTF-8/转义元数据分别验证2MB独立proof/断点、16MB保存批次、64MB完整响应先行拒绝，使用长ID而不缩短实体声明；直接prepare也在调用流静力核心之前拒绝超限完整证明。归一化work不是FLOPs、token费用或CPU硬时限。

## 实际局限与验收记录

一个真实更大曲床冷起仍不能按默认预算完成：18节点、自然长80m、床z=−40+0.1x+0.05y+0.0003xy、固定端(−60,−10,−46.32)、异质材料与点负载、流(0.1,−0.08)m/s，由默认直线seed开始，2000次函数/有限差分预算耗尽。产品明确拒绝，不给假accepted。本独立测试保留该失败边界；未暗增额度、放宽容差、flatten或以无流候选fallback。其它局部seed可行不证明这个冷起必成功，也不证明平衡唯一或稳定。
