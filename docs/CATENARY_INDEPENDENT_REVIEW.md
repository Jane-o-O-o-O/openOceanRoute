# 四种悬链线边界的独立数学审核

这是冻结 0.4 之后的开发审核，不是原厂算法说明或工程精度认证。下述结论只适用于已声明的均匀缆材、自然材料米湿重、轴向线弹性 EA、无流阻、完整仿射床面及床面切向触点的悬空段。有限 EA 的自然长与伸长弧长必须分开；公开手册的 “Cable in Water” 没有据此明确其弹性长度基准。

公开手册物理第 250 页／M242 图例的平床、17 N/m、2000 m 深度、68000 N 顶部总张力，给出 34000 N 底部总张力、60° 顶部角、约 3464 m 入水长和 2634 m layback。在不可伸长极限，独立解析值为 3464.101615 m 和 2633.915794 m；此图例支持顶部角相对水平的解释，不能解决有限 EA 下的长度基准问题。此前实算记录见 `resources/validation/development_next_manual_catenary_figure.json` 和 `development_next_inverse_boundary_research.json`。新计算器独立测试的执行结果另行记录，不能把数学推导当作新 API 已验收的证据。

## 1. 变量、力与几何

沿朝向船端的水平单位向量，床面坡度为 `m`；船端相对其正下方床面的高度为 `D>0`。`w>0` 是每自然材料米的湿重，`H>0` 是水平张力，底端竖向张力为 `mH`，底端总张力为 `B=H√(1+m²)`。设

```text
r = Vtop/H,   u = r−m > 0,
c = √(1+r²), c0 = √(1+m²),
A = asinh(r)−asinh(m),
F = c−c0−mA,
J = ∫[m,r] √(1+v²) dv = (r c−m c0+A)/2.
```

自然长 `S=Hu/w`，伸长弧长 `L=S+H²J/(wEA)`，坡床法向坐标差（此处未除以床面法向向量的模）为

```text
D = H F/w + H²u²/(2wEA).
```

这可以直接从自然材料坐标 `s∈[0,S]` 的力平衡 `V(s)=mH+ws` 与几何方程 `x'=(1+T/EA)H/T`、`z'=(1+T/EA)V/T` 积分得到。不可伸长极限取 `1/EA=0`。顶部角为朝向船端的切线相对水平的有符号角 `atan(r)`；总顶部张力为 `Hc`。这些量不含海底尾缆、拖曳、弯曲刚度或床面摩擦。

## 2. 固定伸长弧长的导数

对给定 `L>0`、有限 `EA>0`，正根唯一且可用稳定式计算：

```text
H = 2wL / [u + √(u²+4JwL/EA)].
e = H/EA,
H'/H = −(1+e c)/(u+2eJ).
Q = u²/c−F,
W = 2J−u c = m(c−c0)+A,
Q' = u(1+mr)/c³,  W' = (1+mr)/c.

dD/dr = (H/w) (1+e c)/(u+2eJ) · R,
R = Q + e u W/c.
```

所有前置因子为正。`m≥0` 时 Q、W 从零严格增加，因此 D 严格增加。对于 `m<0`，设 `a=−m>0`、`r_b=1/a`。Q 和 W 在 `m<r<r_b` 都为正；之后各自严格减少到负值，但**两者的零点顺序不固定**。例如 m=−5 时 Q 先过零；m=−0.25 时 W 先过零。不能以固定零点顺序作为算法前提。

在任何 R=0 处，沿固定 L 的真实导数满足

```text
R' (u+2eJ)c³ = (1+mr)(u+2eJ)² + c³Q(1+e c).
```

若 `Q<0, W>0`，右侧严格为负。若 Q、W 同时为零，右侧仍严格为负。剩余情况是 `Q>0, W<0`，其证明如下。

## 3. W 先过零情况下的严格下降界

取 `y=ar−1>0`、`r*=a+2/a`。令 `A=asinh(a)+asinh(r)`，仍等于上一节的 A。

在 r* 处，`c=c0√(a²+4)/a`，且

```text
A ≥ 2asinh√(a²+2) > 2,
a(c−c0) = c0[√(a²+4)−a] ≤ 2.
```

第一个不等式来自 `asinh(exp(t))` 的严格凸性；第二个来自 `2c0≤√(a²+4)+a`。因此 `W(r*)>0`。W 在 r_b 之后严格下降，故 `W<0` 必有 `r>r*`、`y>c0²`。

定义辅助量

```text
Z = √y (u/c)² − Q.
```

在 r* 处，

```text
Z(r*) = a { A − 3c0[√(a²+4)−a]/(a²+4) } > 0,
```

因为花括号第二项不超过 1.5，第一项大于 2。对 `r≥r*`，令 `t=c0²/y≤1`、`x=c/√y`。Z' 的符号等于

```text
(1+t)x² + 2x − 4.
```

由恒等式 `c²c0²−y²=u²>0` 得 `t x²>1`。该表达式对 x 严格增加，故大于等于 `(1+1/√t)²−4≥0`，且实际为严格大于零。因此当 `Q>0, W<0` 时有

```text
Q² < y u⁴/c⁴.
```

改用 `k=e u=wS/EA` 和 `p=wL/EA`。固定 L 的关系为 `p=k+k²J/u²`。记 `b=−W>0`。沿真实固定 p 曲线，

```text
−k' = k²b/[u(u²+2kJ)].
```

R=0 等价于 `k=kcrit=cQ/b`。临界曲线的导数为

```text
−kcrit' = u y/(c²b) + Q E/(c b²),
E = r(a c0+A)−c > 0.
```

E>0 可由 `r>r*≥2√2` 和 A>2 直接得到。在任一交点，

```text
−k' < c²Q²/(b u³) < u y/(c²b) < −kcrit'.
```

所以 kcrit 在每个交点下降严格快于真实 k；`R=(b/c)(kcrit−k)` 的每个零点都满足 R'<0。这补齐了另一种 Q/W 零点顺序，不需要假定小伸长、小坡度或先扫描 B。

## 4. 根的完整计数和显式有限域

对于 m<0，`R(r_b)>0`，而 `R(r→∞)<0`。上一节证明每个零点都是严格的正到负穿越，所以只有一个驻点，即严格最大值。不可伸长极限 e=0 则由 Q' 的同一符号变化直接得到唯一最大值。

固定伸长 L 时，`D(r→m)=0`、`D(r→∞)=L`。负坡最大值严格大于 L。因此无额外物理上界时：

| 目标 D | 有限、正 H 的数学根 |
|---|---:|
| 0<D<L | 1 |
| D=L | 1；另一个仅是 r→∞、B→0 的极限，不是根 |
| L<D<Dmax | 2 |
| D=Dmax | 1 个重根 |
| D>Dmax 或 D≤0 | 0 |

正坡／平床是单调情形，D=L 的渐近极限也不能列为有限根。对于固定自然长 S，先减去 `wS²/(2EA)` 后，对 `F/u` 作同样的单峰计数；对于固定顶部总张力，响应为 `T[F/c+(T/2EA)u²/c²]/w`。顶部角已知时 H 为高度方程的唯一稳定正二次根。顶部总张力不自动规定竖向分量为正；若支持 r<0，按总 B 过滤时须考虑 `H=T/c` 在负 r 段的方向变化。

在**固定伸长 L**的反解中 H(r) 从正无穷严格降至零。因此声明的有限 `Bmin≤B≤Bmax` 可严格映射成一个有限 u 区间；在该区间检查唯一驻点是否存在，再把区间按驻点分成至多两个单调分支进行括根。无需不断扩大 B 搜索上界，也不能把数学无限域计数冒充有界 API 实际根数。每个数学根还必须独立通过完整床格覆盖、模型海面、自然长度上限、力平衡和原 forward 几何验证；一个根失败不能抹去另一个根，不能把触点投影回床格补救。

## 5. 接近双根与重根的数值分类

应报告声明域、目标残差容限、驻点位置、峰值及峰值的可解析／数值误差界。两个分支各有明确符号括区间时，应保留两个不同根，即使 B 很接近。恰好驻点目标只有一个根并应标明条件不良；若目标与峰值之差小于可信峰值误差而无法区分一根／两根／无根，应明确返回未分辨状态或拒绝，不以宽泛的 B 去重阈值宣称“已完整枚举”。

不能因为高度残差接近零就将一个渐近 B=0、超出声明张力域、未覆盖床格或未完成迭代的状态列为 accepted。完整根枚举与某根是否可用是两个独立结论；存在两根且未显式选择时不应默认应用其中一根。任何结果都是研究预览，不自动修改工程或建立动态初态。
