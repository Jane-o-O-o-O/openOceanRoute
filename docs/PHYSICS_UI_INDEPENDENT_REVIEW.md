# 定端初态与持续任务界面的独立接线审查

这是冻结0.5之后的开发审查，不修改历史发行物或验收计数。审查源码为 `SimulationPanel.tsx`、`StaticBathymetryPanel.tsx`、`EquilibriumInitialPanel.tsx`、`PlanVoyagePreparation.tsx`、`VoyagePanel.tsx` 和 `Scene3D.tsx`，并核对真实后端字段。独立只新增 `web/tests/voyage-job-response-review.spec.ts` 及本文，不改业务、界面或其他人的测试。

## 1. 找到的实际错误及修复

持续任务允许请求期间切换任务。原 `VoyagePanel.cancel()` 对请求前选中的A调用API，await之后直接 `setJob(next)`，没有核对当前是否已改选B，也不清除B的result/loadedResult。用户取消A后立即打开B，A的迟到响应会把标题与状态改回A，但保留B的物理帧、材料摘要或下载内容。A没有可读结果时，错误混配会持续显示。

原resume也会在迟到响应后自动choose A的子任务，覆盖用户已经选中的B；原saveCheckpoint则会在用户已切到B后仍静默下载A的检查点。它们不是求解器错误，但会错误关联可审查的工程证据。

维护者已给cancel/resume/save加入真实请求任务ID、当前selectedRef及mounted判断。迟到操作仍按服务器实际结果执行，任务列表可刷新；没有把已成功创建的子任务当作不存在。仅当前选择仍对应原请求时更新任务或下载检查点，新的断点文件名包含实际任务ID。

## 2. 真实浏览器反例验收

独立生产浏览器命令只运行本文件，外部同源服务为 `http://127.0.0.1:8767`，API为 `/api`，生产dist为本轮已修guards的构建。三个用例全部通过，实际输出 `3 passed (5.5s)`，零跳过、失败或重试；这是局部专项结果，不代表完整浏览器回归。

每个迟到响应都先通过 `route.fetch()` 访问真实API，再只延迟浏览器收到该实际响应。没有替换JSON、模拟状态或生成假物理帧。B为真实完成的0.2 s任务，并用另一底张力与A区分；断言包括完整下载JSON与真实API原结果一致。

| 专项 | 实际验收 |
|---|---|
| 取消A后等待真实响应时切到B | 保持B完整任务ID、B的帧/摘要和完整下载结果；不改回A |
| 恢复A，真实子任务已经创建，但响应迟到时切到B | 验证子任务parent_job_id确实为A，同时保持B选择和完整结果 |
| 取A完整断点的响应迟到时切到B | 不触发A的迟到下载；重新取B时文件名含B ID，完整checkpoint等于B实际结果 |

测试仅清理自己创建的真实任务；取消在实际完整分块边界完成，删除不作用于其他任务。测试输出隔离到 `web/artifacts/dev-0.6/voyage-response-review/test-results`，没有运行或改动完整suite、历史截图或冻结包。

## 3. 其余接线的源码与合同核对

以下是源码/真实后端合同核对结论，不冒充新增浏览器操作验收：

- 静力转动态按钮只对当前签名、accepted且frictionless的定端结果出现。传递原床、明确端点、自然长/自然段和实际节点作为迭代种子；显式设置同质、EI=0、零流、零初始速度与零船速/放缆的草稿，清除旧混材、实体和恢复草稿。动态入口仍重新求静力和独立验收，未把显示nodes或外部accepted结果改名为resume_state。
- 新定端初态的预备请求、静力请求和计划窗口请求均绑定完整输入快照；编辑后迟到响应不能重新显示旧证明。动态实际结果也绑定工程及配置签名，旧形状、摘要、proof和下载被隐藏或禁用。数值初值没有被宣称为已经平衡。
- 计划窗口同时传递真实地理床格和地理锚/模型Z/自然库存。准备结果完整保留plan_mapping，应用后提交采用其实际config；修改工程或任务配置使该准备失效，不能丢掉映射后继续当作原窗口提交。
- 普通动态恢复保留完整检查点中的材料、锚、床格、初始proof和数值方案；恢复运行不会调用freshDynamicConfig来重新生成库存。持续任务恢复走真实保存状态及其制造映射，后端继续执行工程SHA和物理一致性校核。
- nullable touchdown和bottom_tension_n在持续张力图和轨迹中不补零、不跨缺失接触区间画线。Scene3D仅在实际touchdown非空时画触点；离床固定锚以独立支持点显示，不能把锚端冒充触地位置。静力定端视图不画默认触点。

未找到其余可导致错误初态、重复初始放缆或恢复绕过材料/床格校核的接线阻断。后端材料和地理映射的独立实际验收另见 [PLAN_EQUILIBRIUM_REVIEW.md](PLAN_EQUILIBRIUM_REVIEW.md) 与 [EQUILIBRIUM_INITIAL_REVIEW.md](EQUILIBRIUM_INITIAL_REVIEW.md)。

## 4. 不外推的结论

当前界面说明定端初态是首次作业命令前的零速度研究快照，不是施工历史重建；固定端可离床，touchdown需实际接触。初始同湿重/EA、零抗弯、无已投入实体、无流无波及严格力/穿床验收仍由后端强制。准备时的自然材料库存不会在首块再次放出。

正确异步关联和真实静力转接不提供投影尺度、海图基准、运动铺设准稳态、曲床长期误差或海试精度保证。已有Ship Plan移动偏移仍是局部平底初估，其实际曲床初态不认证计划触点跟随。完整目标中的混合初始物性、实体接触、摩擦加载历史和现场校准不因本界面通过而视为完成。
