# 0.4 wheel 独立运行验收范围

本记录说明新增的实际发行验收脚本及证据边界。0.1、0.2、0.3 冻结文件不改写。此时只完成脚本与外目录源码副本预检；**正式 0.4 wheel 运行报告尚待构建后生成**，不能将预检写成发行物已通过。

## 安装隔离方式

`scripts/smoke_release.py WHEEL --report REPORT.json` 从 wheel 的唯一 `METADATA` 动态读取 OceanRoute 名称和版本，将该值传给全新子进程，并核对实际模块版本及 `/api/health`。wheel 解压至临时目录，子进程工作目录位于该目录，`PYTHONPATH` 仅指定该目录，关闭用户 site-packages；运行数据库、任务目录和锁均位于临时目录。

逐一检查原有17个关键模块以及新 `coordinate_transforms/terrain_sources/bathymetry/terrain_bathymetry` 共21个模块的 `__file__` 必须处于该解压目录。即使调用解释器已有 editable 源码安装，也不能悄悄从仓库加载这些模块。成功报告包含实际路径、wheel 的字节大小、SHA256、METADATA 版本、解释器与平台。

依赖仍复用调用解释器的已安装包，包含 terrain 可选依赖 Rasterio。这是 **wheel 载荷＋已有依赖＋真实 ASGI lifespan** 验收，不是新虚拟环境 `pip install`、所有操作系统、console entry point、免 Python exe 或浏览器测试。干净安装与 portable 启动由独立发行流程记录。TestClient 是实际 FastAPI 请求与后台任务调用，不用 stub 代替求解或持久化。

## 保留的真实流程

原有静态资源/手册、schema1 核算与修订保护、schema2 多路径/共享替代制造与恢复、固定宽度及多行 RPL、minimum-curvature/BLN/完整栅格切片、Seismic 合成正演和估计、后台连续航程及实际关闭/重开、ShipPlan 准备/初始库存/续算一致/过期工程拒绝均保留。

## 新增流程及判断依据

- CRS：实际 WGS84→UTM50N 对照明确 `(603224.6404290784,2433164.428653589)` m，再反向恢复118°/22°；要求非 ballpark 与最佳操作可用。包含一个有效点和纬度95°的坏点，后端须保留坏行、返回 null 输出并禁止部分应用。
- 多源：真实 XYZ 背景和有孔洞的 Surfer 源经 normalize/query/profile，四点结果约300/100/100/null；实际检查孔洞与域外回退顺序、source_id、库摘要、水平操作信息和缺测。将剖面及库迁移为顶层共享 schema2、复制替代路径、整体保存，变更背景优先级后两路径均必须停止旧底距计算，即使路线点有55m深度也不能补救。关闭并重开后逐字节结构等价的源资料仍在，实际新查询改由100m背景优先。
- 来源→二维动力：从真实12m深度源采样25节点局部网格，明确给 `sea_surface_height_m=0.75`，必须计算 `z_model=-12.75m`；缺少该声明则422，不推断潮位。检查来源摘要、真实逐点来源及完整网格。
- 实际二维求解：1.5s小例使用上述完整网格，实际进入v3接触模型、schema2物理断点和材料守恒检查。0.75s断点直接续算与不中断结果的位置、速度、自然长、材料KP、法向、正常/摩擦冲量必须在既定数值容差内一致。
- 持久任务：首个0.75s二维后台任务完成，真实退出 app lifespan 释放 writer ownership；同目录新 app 重开，读取完整grid/来源/接触断点，再后台续算0.75s。最终状态再次与实际1.5s直接求解核对，放缆总量须0.6m，不重置物料、床高或模型版本。

所有报告只在上述断言完成后写出；返回内容须严格有限JSON。报告中的 `True` 对应实际执行断言，不是预填的产品能力清单。派生床高与来源都是显式合成案例，不当作海测数据。

## 已完成的脚本预检

将当前0.4.0的 `oceanroute` 复制到临时外目录，以相同 `SMOKE_CODE` 运行。全部旧、新流程在1.26s内通过；21模块均从该副本加载。UTM数值符合固定参照，两个共享路径旧剖面均停用，源网格/二维断点实际保存和重开一致，材料余额残差约4.44e-16m。此时间仅为该本机小例子进程耗时，不能当作其他项目的性能保证。

正式 wheel 报告待根代理构建后运行并记录实际 wheel SHA256。没有增加长时间二维网格收敛验收、细网格参考、海试、土体摩擦校准、垂直基准转换、完整静摩擦或材料段连续碰撞；单例求解残差通过不能证明工程接触载荷准确。
