# 二维静力到动力初态的独立材料与数值审查

本文针对冻结0.5之后的新开发接口，不改变0.5产物或验收结果。独立测试为 `tests/test_equilibrium_initial_review.py`，本轮19项真实验收通过；它不是下一版本的完整回归或发行验收。静力候选通过、有限段力残差通过和短时动力保持均不代表原厂等效、加载可达性、稳定性或海试精度。

## 1. 当前受支持的初态合同

动力入口仍为 `POST /api/simulation/dynamic`，请求 `{project,config}`。显式新字段为：

```json
{
  "initial_equilibrium": {
    "schema": "oceanroute.dynamic.initial-equilibrium.v1",
    "vessel_position_m": [3,-4,-2],
    "anchor_position_m": [-24,-4,-15],
    "rest_lengths_m": [12,2,3,1,4,2,3],
    "solver": {
      "force_tolerance_n": 0.01,
      "relative_force_tolerance": 1e-7,
      "contact_tolerance_m": 1e-8,
      "max_solver_iterations": 300,
      "max_function_evaluations": 2000,
      "max_segment_samples": 20000,
      "max_work_units": 200000000
    }
  }
}
```

上例展示可选初始化对象，不代替主配置中的床格和物性。可另提供 `initial_positions_m`，必须是主 `nodes` 数量的完整N×3数组；省略时由静力求解器构造可行迭代种子，种子不具有平衡成功含义。自然材料长度必须以 `natural_length_m` 或 `rest_lengths_m` 二选一。主 `seabed_grid` 保持完整二维双线性场，主 `nodes` 为6..80；自然段长、端点和查询轨迹都必须满足实际覆盖。

初始化在当前床格、端点和实际初始物性下重新调用静力求解并独立验收，不接受外部 `accepted:true` 结果或可视帧。主配置/显式材料区间提供湿重、EA、干质量及水动力参数；初始化对象不得偷偷覆盖它们。当前初始区间只支持均匀湿重及EA、EI=0、无已部署组件载荷、无海流或波浪加载。静力接触无摩擦；动力μ≥0可声明，但这不表示已经重建静摩擦历史。

这是首次施加运动命令之前的零速度快照。后续船速、放缆和允许的物料转接会在内部步真实施加；并不声称初态已是移动铺设的准稳态。原始输入和初态力验收存于 `result.initialization` 及 `checkpoint.state.initialization_provenance`。新检查点为schema3，采用 `implicit-compliant-material-nodes-equilibrium-prestress-v4` 数值方案；恢复使用实际已保存的动力位置、速度和自然材料，不重新求静力。旧检查点保留原有版本和冷起乘子方案，不隐式升级。

## 2. 离散力、自然长度和端点支持

节点顺序为船→固定锚；对段i，设自然长rᵢ、几何直段长ℓᵢ、EA及单位方向dᵢ（节点i→i+1）：

```text
Tᵢ = EA max(ℓᵢ/rᵢ − 1, 0)
F_internal[i]   += Tᵢ dᵢ
F_internal[i+1] -= Tᵢ dᵢ
q[0]=r₀/2, q[j]=(rⱼ₋₁+rⱼ)/2, q[N−1]=r_last/2
F_weight[j] = (0,0,−w q[j])
```

静力能量为 `Σ EA max(ℓ−r,0)²/(2r)+Σ w q z`，与以上离散力相符。EA是N，w按每自然材料米计N/m；不能使用伸长弧长或显示折线长计算质量和湿重。自然段长r必须原样传递到动力，保持总量和不均匀材料网格。

自由接触节点只允许实际床法向非负支持 `N n`；需要切向支持的初态不能以任意动力μ补出静力历史。静力与动力都保留全三维节点力。固定端支持为 `−(F_internal+F_weight)`，包括端节点半段湿重；它不等于首段或末段缆张力，也不是床摩擦力。固定锚可离床，此时仍是明确外部支持端。

静力默认米容限与旧动力接触阈值不同，不能把小于1e−6的穿透直接带入动力。本合同限制初始化接触容限≤1e−8并复核实际节点与整段；不足时拒绝，不投影位置后继续信任旧张力。静力法向支持是N；time0尚无动力时间步，不能随意乘h制造一个“已发生”的接触冲量。初始动态冲量为0，静力支持及验收另作来源记录。

## 3. 质量、材料坐标和制造库存

均匀初始区间的节点干质量为 `m_dry q`，有效惯性质量为 `(m_dry+C_a ρπd²/4)q`，湿重仍为 `w q`。干质量、湿重和附加质量不能互相替代。明确干质量必须大于w/g；直径、流体密度和附加质量系数影响惯性/拖曳而非额外制造材料。

令L=Σr，最旧材料制造坐标为O，则：

```text
node_material[j] = O + Σ(i=j..N−2) rᵢ
top_material(0) = O + L
anchor_material(0) = O
paid_out(0) = 0
Σ rest(t) = L + paid_out(t)
```

L是整个初始有限窗口自然材料，可能包括已床接触尾段，不能全部称为“水中悬垂长”，也不是路线平面KP。规划桥接用 `O=当前计划制造顶KP−L`，必须非负且整个区间有实际库存及物性覆盖；不能扩库存、重新回算制造量或在首块重复放出L。新放缆只来自后续命令时间积分。

不均匀首段可能大于两倍平均段长。旧动力的细分条件每一步执行，即使放缆为0，因此若新初态继续采用平均r作为细分目标，会无命令重划平衡网格。新初态采用 `segment_target=max(rest)`，保持初始网格；后续明确放缆达到阈值才细分。船端和离床锚位置原样保留，水下船端的z应成为无新heave时的高度基准。

## 4. 两类独立数值对照

曲床例使用 `z=−40+.1x+.05y+.0003xy`、船 `[0,0,0]`、锚 `[-60,-10,-46.32]`、L80 m、18节点、w4、EA10000。当前独立复算的静力通过：自然长度约80 m，显示弦长81.57679122661811 m；从各段几何和Hooke法重构，最大节点残力0.002325865542 N。首段张力305.107158888 N，船端支持为 `[134.97631434,22.59888792,282.10401475] N`，其中含9.411764706 N端半湿重。

同一床格的旧fresh动力初始化得到自然长度63.405801119365805 m、锚 `[-41.91987422,约0,-44.19198742]`。它是另一套边界/材料状态，不是上述静力的映射，也不能凭相同床格把两者作为同一初态。

另一对照完全由离散力递推构造，不调用静力或动力内部helper：指定不均匀自然段r、固定H及底部垂向基准V₀，令各段中点材料坐标 `sᵢ=Σ(k>i)rₖ+rᵢ/2`。取 `Vᵢ=V₀+w sᵢ`、`Tᵢ=hypot(H,Vᵢ)`，则从锚向船的每段几何向量为 `rᵢ(1+Tᵢ/EA)(H,0,Vᵢ)/Tᵢ`。相邻段垂向力差恰等于节点两半湿重，水平力相消，因此构成严格离散平衡。

测试使用r=`[12,2,3,1,4,2,3]`、H150 N、V₀15 N、EA10000 N、w4 N/自然米、水下船 `[3,-4,-2]` 及全离床已知床格。该例同时检查不均匀材料不改写、悬空锚不贴床、无接触时不伪报touchdown、真实有效质量、端半湿重、零速度与短时保持。短时一致性不是稳定性证明；曲床一般候选仅满足明确残力容限，不能要求任意时间步永远精确不动。

## 5. 预应力与真实动力保持

接线草稿仅搬入平衡几何/自然长，而每步仍从零弹性乘子开始。闭式初态仅约7×10⁻¹² N力残差，却在零命令0.1 s后产生微米级漂移；16、32、40次迭代结果相同，标量compliance残差约10⁻¹⁷ m。因此“弹性约束残差通过”不能代替完整节点力平衡或证明初态没有数值启动沉降。

预应力不能只写入诊断张力或乘子数组。对每步h，重新从当前实际自然段/几何算Hooke张力，取 `λᵢ=−h²Tᵢ`，并把相应实际内部力位置增量 `h² M⁻¹F_internal` 加入外力预测点；法向支持同样用 `λ_N=h²N` 并施加 `M⁻¹λ_N n`。否则初始化乘子与位置修正不对应，会遗漏或重复预应力。随后仍运行完整约束、接触和命令求解，不冻结节点。

本轮闭式无接触例、0.1 s、32次迭代的独立比较为：

| 内部步长h | 冷起接线草稿最大位置漂移 | 预应力方案最大位置漂移 | 预应力方案最终直接Hooke节点残力 |
|---|---|---|---|
| .008 s | 1.11865×10⁻⁵ m | 4.80×10⁻¹⁴ m | 4.59×10⁻¹¹ N |
| .004 s | 3.10955×10⁻⁶ m | 1.21×10⁻¹³ m | 3.00×10⁻¹¹ N |
| .002 s | 7.64570×10⁻⁷ m | 1.78×10⁻¹⁵ m | 7.03×10⁻¹² N |

该否定反例和修复只针对新声明平衡初态路径，不重写冻结0.5历史结果。独立1e−7 m位置/1e−6 m/s速度断言没有放宽。另作真实船速.2 m/s、放缆.25 m/s、.08 s例：船位前进.016 m、自由缆节点实际响应、新增自然材料.02 m、干质量/湿重相应增加，固定锚保持。它排除“为通过保持测试而把静力节点钉住”的假实现；仍不能外推为任意时间步、冲击或复杂床动力收敛。

## 6. 初始化预算与持久化验收

静力初始化使用独立默认200M、硬上限2B的归一化工作预算，不能以动态12M额度掩盖昂贵初始化或放宽动态限制。连续航程只在首块计入明确初始化工作，后续恢复块不重解不重复计账。实际预算不足时显式拒绝；归一化费用不是FLOPs、CPU硬时间或token计量。

独立19项验收命令为 `.venv/bin/python -m pytest tests/test_equilibrium_initial_review.py -q`。内容包括真实HTTP、实际不收敛静力/失败预算/不支持物性拒绝、初始制造库存与首块放缆、全字段检查点恢复、修改初始化请求后拒绝、虚假力诊断拒绝、后台任务关闭重开及子任务实际续算；未用mock替代静力或动力。来源、请求、初态完整快照及公开验收数字都与复核值相符，不能只检查记录中的 `accepted:true`。重新计算公开校验和仍不能使旧证明与修改的请求相符；但哈希不是身份认证或防恶意篡改的签名。API输入不得把静力候选改名为resume_state绕过初始化校核。

曲床地理桥接还需使网格、船端、锚端与真实计划使用同一米制投影及明确原点，全部一起重基准；不能把LOCAL任意网格猜成地理来源。固定锚与计划目标KP/触地点区别必须保留并公开实际偏差。桥接业务由独立plan模块负责，本测试不以其内部投影helper生成黄金坐标。

## 7. 完整目标中仍未覆盖的部分

这一步提供实际二维床、明确固定端和自然材料的静力初态映射；不缩减完整软件目标为这一子集。后续仍需真实静摩擦加载历史、初始混合物性/组件/抗弯、带流或运动铺设准稳态、转接几何与实体接触、自动网格细化、变深长航程误差及现场校准。现有曲床动态粗化保持拒绝，不能把床场flatten为平床取得长航程承诺。
