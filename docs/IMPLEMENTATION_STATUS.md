## 验收证据

当前443项后端与23项完整浏览器测试通过；压缩包全新环境首次安装及443项回归也通过，详见 `RELEASE_NOTES.md`。已验证编辑/撤销、保存/恢复与冲突、实际下载、移动布局、工程转换、约束和制造清单、ShipPlan/Look Ahead/张力搜索、DTM/混合材料/断点，以及海况、调查和维修研究。新模块使用真实API和数值对照，不以界面图标作为验收。

原厂黄金基准、实测造价/地形、海试张力/触地点、百万点性能和长期可靠性尚未验收，当前不能声称完整原厂功能与精度等效。
