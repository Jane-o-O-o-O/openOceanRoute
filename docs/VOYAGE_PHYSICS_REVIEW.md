# 连续施工研究求解：独立物理验收

本记录审查 `oceanroute/voyage.py` 的真实分块续算与海床网格粗化。验收代码位于 `tests/test_voyage_physics.py`；审查没有修改该模块。它是独立研究模型的数值审核，不能证明 Makai 原厂等效、实船精度或跨洋施工安全性，也不改变已冻结 0.1 包的验收记录。

## 计算边界和审核方法

连续块恢复完整物理 checkpoint，包括节点位置/速度、材料坐标、各段自然长度和物性、放缆累计量、船指令时基、原始锚端、接触状态及数值参数。粗化合并已稳定接触海床的相邻两元，保留原锚端和全部材料区间。它没有删掉海床尾缆，也没有把触底点改成新的固定边界。

测试以 `simulate_lay` 保留所有初始/新增节点的 120 秒解作为数值基线。两个解必须使用相同物性、船速、放缆率、海流、内部步长和输出时基；所有实际输出时刻逐帧比较。基线是现有研究求解器的未粗化解，不是独立实船真值。位置比较包括两个方向：完整网格在保留材料点上的插值，以及粗网格在**全部完整网格材料点**上的重构。后者会发现删除中间节点后丢失的材料位置。

另从粗化前/后的真实 checkpoint 数组独立计算：自然长度总和、干质量、等效质量、湿重、线动量 `Σ mᵢvᵢ`、角动量 `Σ xᵢ×mᵢvᵢ`、质心、动能、受拉轴向弹性能。测试不直接信任模块输出的 `before/after` 审计数值。

## 可运行基准

在项目根目录运行：

```sh
.venv/bin/python -m pytest -q tests/test_voyage_physics.py
```

基准输入如下；将 `current_y_m_s` 分别设为 `0`、`0.02`、`0.1` 可运行三个横向海流算例：

```python
from oceanroute.voyage import run_voyage

result = run_voyage({}, {
    "simulation": {
        "depth_m": 20, "bottom_tension_n": 50, "wet_weight_n_m": 4,
        "ea_n": 1e6, "ei_n_m2": 0, "nodes": 12,
        "ship_speed_m_s": 0.5, "payout_m_s": 0.6,
        "internal_dt_s": 0.05, "dt_s": 1,
        "solver_iterations": 24, "seabed_friction": 0.5,
        "current_y_m_s": 0.0,
    },
    "duration_s": 120, "chunk_duration_s": 10,
    "adaptive_mesh": {"target_nodes": 12},
    "max_output_frames": 256,
})
```

放缆真值为 `0.6 × 120 = 72 m`。粗化不能改变初始材料总长或该累计放缆量；两者之和必须与最终自然长度一致。测试要求所有块及未粗化基线均通过各自求解器的数值收敛守卫，整个 121 帧序列的材料坐标、速度、触底点和顶/底张力误差满足声明的实验阈值。

## 审查发现及修复要求

以下问题已通过可执行反例交给模块作者修复；当前代码加入相应守卫，验收文件保留这些反例作为回归：

1. 请求终点正好达到粗化审计条目上限时，旧代码仍将已完成结果标记为 `stopped/mesh_history_budget`。最终时刻不再需要粗化，必须返回 `completed`。
2. 节点容量估算曾使用所有历史船指令的最大放缆率。历史放缆已经停止时，会把仍可正常继续的 253 节点状态误判为容量不足。当前及未来指令的计算不应包含已经结束的放缆阶段。验收以声明为制造网格的 253 节点状态，与直接动态续算逐项比较。
3. 两个 chunk 端点都接触海床且低速，不能证明中间时段保持接触和低速。当前真实求解在每个内部步提供独立诊断副本，持续稳定材料坐标取整个区间交集，并要求最小稳定时长。缺该证据时必须拒绝粗化；诊断回调不能修改积分器数组。
4. 未收敛的原/粗双解不能作为粗化通过依据。当前守卫同时检查收敛、位置、速度、保留节点接触集合、触底点、顶/底张力以及内部步峰值张力。
5. 一段规定升沉序列只覆盖实际终点时，额外的未来 probe 可能没有合法输入。此时必须保留未粗化状态；不能外推升沉、捏造通过或丢失已完成 checkpoint。
6. JSON schema 的版本字段不得接受布尔 `true` 作为整数版本 `1`。该反例使用重新计算的合法校验和，确保测试针对 schema 严格性，而非仅校验和损坏。
7. 总工作量预算必须传入每次真实动态计算，包括波浪速度和双解 probe；失败探针保守计费必须明确标注。`estimated_work_units` 是声明的工作量估计/上限收费，不是实际 FLOPs 或实测 CPU 时间。

### 材料位置误差是独立的验收条件

审查旧双解比较方式时，120 秒基准中保留节点位置差最多只有 `0.00435 m`，但反向重构被删材料点得到下列误差：

| 横向海流 (m/s) | 保留节点最大位置差 (m) | 全材料重构最大位置差 (m) | 各次粗化质心位移范数累计 (m) |
|---:|---:|---:|---:|
| 0 | 1.60e-13 | 0.200634 | 0.049216 |
| 0.02 | 0.0000338 | 0.154777 | 0.033149 |
| 0.1 | 0.0043495 | 0.079182 | 0.008098 |

**此表是已发现的旧比较方法反例，不能当作最终验收通过结果。** 直线上的两个松弛元也可能具有不同压缩程度。几何中点到直线的距离为零，并不能保证该材料点在合并元中的自然坐标位置不变。若两元自然长度为 `L₁,L₂`，删除中间节点后该材料点的线性重构为 `x̂ = x左 + L₁/(L₁+L₂) × (x右−x左)`，必须比较 `|x̂−x中|`。只使用受拉应变 `max(长度/自然长度−1,0)` 也会隐藏这种松弛材料位置差异。

当前代码已加入删除前的材料位置重构守卫 `max_material_position_shift_m`（默认 `0.001 m`）、**有符号**轴向应变变化比较（默认 `1e-5`，压缩亦比较）和双向全材料 probe。测试额外制造保持完全共线、但材料位置或压缩分布变化的节点状态，验证几何距离为零仍会被相应守卫拒绝。

## 修复后的完整轨迹实测

|---:|---:|---:|---:|---:|
| 0 | 1 / 1 | 37 / 38 | 1.53e-13 | 1.89476e-5 |
| 0.02 | 0 / 0 | 38 / 38 | 0 | 0 |
| 0.1 | 0 / 0 | 38 / 38 | 0 | 0 |

三例均真实达到 120 秒，所有块及未粗化基线均通过数值收敛守卫。全部材料点重构速度、触底点、顶/底张力差均为零。无流例粗化产生的自然长度累计缺陷约 `7.1e-15 m`、等效质量缺陷约 `−1.42e-14 kg`、线动量缺陷为零，粗化质心位移范数累计为 `1.2292e-6 m`。干质量、湿重及轴向弹性能累计缺陷为零。放缆累计 72 米，最终自然长度平衡残差低于 `1e-8 m`。

横向海流算例未找到满足严格守卫的区段，正确保留了全部节点。不能为了得到更多删除记录而降低守卫。测试的 `0.02 m` 全区间重构阈值只适用于这个声明的数值实验，不能推断为任意海况、时长或材料的工程精度。

### 长时间计算日志：单模型运行

另查阅团队实际生成的 `resources/validation/voyage_1800s.json`。该文件保存可复现配置和运行摘要：平床无流、深度 10 米、水平初始张力 10 N、湿重 4 N/m、初始 16 节点、船速 0.5 m/s、放缆率 0.6 m/s、内部步长 0.05 秒、24 次迭代、目标 96 节点、每块 30 秒、120M 工作量预算、128 条粗化记录上限。

该单次实际运行完成 1800 秒 / 60 块，56 条接受记录、1184 次节点合并，最终 117 节点，实际放缆约 1080 米；自然长度平衡残差 `7.285e-10 m`，所有块通过数值收敛，局部完整材料 probe 的最大位置差 `3.775e-5 m`。工作量估计 109,146,264，主机运行耗时约 42.1 秒，耗时不是其他主机的性能保证。

它证明该声明平床算例在连续粗化后未耗尽节点和工作量容量。**它没有与 1080 米放缆的完整细网格轨迹逐帧独立对照；局部 probe 不等于 1800 秒全局误差保证。** 完整细网格超过现有 256 节点容量，因此不能用这个日志声称已经验证千米级全材料位置精度、复杂海况或无条件全航程支持。

## 守恒的范围

自然长度、干/等效质量、湿重及线动量可以在一次转移中保守地计算。针对实际稳定几何的低速非零速度制造扰动，测试确认线动量守恒不是仅依赖所有删点速度为零的退化情况。质量分配后速度混合通常降低动能；允许的动能变化及轴向弹性能变化仍需满足策略阈值。

角动量和质心位置没有被证明严格守恒。模块应输出实际缺陷。`max_center_of_mass_shift_m` 是**每次删除**的上限；多个合并的累计位移不能用单次阈值宣称有保证。短 probe 是局部模型一致性检验，无法保证数小时后的误差或后续触底尾缆重新滑动时的应力传播。

## 必须保留的限制

- 当前粗化只适用于零弯曲刚度、近直线、已持续稳定接触的平床区段，不得跨材料边界，也不得靠近附属体、船端或原锚端。曲床、不稳定接触、明显弯折及弯曲刚度区段继续保留原网格；达到容量/预算时只能停止并保存已算状态。
- 触底摩擦沿用研究积分器的湿重基础摩擦近似，没有恢复工程级法向接触反力或证明静摩擦安全裕量；数值收敛不等于摩擦模型已校准。
- 原锚端仍固定，坐标是局部 ENU 笛卡尔坐标。延长时间不自动提供完整自由拖动跨洋缆线、全球曲率、WGS84 路由/海底数据驱动、设备接口或实时船控。
- `frames` 经过保留数量限制时只保留真实样本；不能由稀疏帧重猜速度或 resume 状态。恢复必须使用整个 voyage checkpoint 内的真实 physical checkpoint 与粗化历史。
- `completed` 仅表示真实到达所请求的局部模型终点。`stopped/cancelled` 必须同时展示真实 `end_time_s` 与 `requested_end_time_s`；部分计算不能包装成完成。

修复前的材料误差反例继续保留在本文和测试中。修复后数值验收以本节的实际配置及上述完整轨迹对照为范围，不为任意全航程或原厂等效结果出具工程结论。
