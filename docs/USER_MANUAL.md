# OceanRoute 用户手册

版本 0.4 / 2026-10-04 / 独立海缆规划与敷设研究软件

本文对应0.4开发版，新增显式投影坐标编辑、共享多源地形及二维变化海底接触。历史发行包单独保留；版本验证与限制见 `RELEASE_NOTES.md`。

## 1. 安装和启动

安装 Python 3.10 或更高版本，将交付包解压到可写目录。macOS/Linux 执行 `python3 launcher.py`，Windows 执行 `py launcher.py`。启动器创建 `.venv` 并安装依赖，首次安装需要联网；完成后浏览器打开 `http://127.0.0.1:8765`。按 Ctrl+C 结束服务。源码环境也可依 README 分别安装 Python 依赖和编译前端；已编译发布包不需要 Node.js。

端口被占用时，在启动器命令后增加 `--port 8766`。默认只监听本机，工程不上传至 Makai 网站。初次打开显示合成演示工程，水深、物性和价格都是示例，不能用于真实决策。“新建”得到两点空白工程，填写实际位置、缆材库、测深和费率后再规划。交付包 `examples/` 提供完整短路线、制造清单及工况合成示例。

## 2. 坐标、单位与三种里程

路线使用 WGS84 十进制度，东经/北纬为正。长度和水深为米，力为 N；缆段单位长度湿重为 N/m、质量为 kg/m，附属体/浮标总质量为 kg、净湿重为 N。时间和价格按字段明确标注。界面 KP 可显示 km，标注 m 的输入仍须填米。水深向下为正；未知保留空白，不能用 0 代替。模拟局部三维坐标的 z 轴向上，与水深符号相反。

路线 KP 沿地理曲线累计；海底距离沿有效 KP-水深剖面累计；电缆 KP 沿实物装配累计。附加缆长和附属体会使三者不同。SLD 是实物缆单线图，不是地图路线。余缆输入 `1.5` 表示 1.5%；表面余缆为 `100×(缆长/平面距离−1)`，底余缆为 `100×(缆长/底距−1)`，负值表示缆量不足。

投影坐标在点资料或工程工具中编辑：明确源EPSG/WKT、X/Y和原生单位，先真实转换预览，再明确应用；可把当前WGS84坐标反转换到源坐标系核对。全部点成功才开放应用，基准最佳网格缺失时拒绝，适用区外显示警告。修改输入或工程后旧预览失效。已有制造域的点须经约束求解，不能绕过固定滑动点或库存校核。深度不随水平转换变更，地图任意投影切换及原厂CSF仍未兼容。详细合同见 `COORDINATE_NOTES.md`。

## 3. 建立与编辑路线

“路由工作空间”包含地图、选中点资料及剖面/SLD/RPL。点击地图点或表格行选择点，拖动改变位置；在点资料或“路由位置表”准确输入名称、经纬度、水深和备注。添加点可在选中位置后插点或在地图追加点。至少保留两个点。

“工程设置”选择恒向线或 WGS84 测地线。地图显示加密后的实际曲线，日期变更线输出分段处理。默认离线经纬网；开启 OpenStreetMap 才需网络。修改位置后重新计算，等待状态栏“计算完成”再固定缆长或导出。移动路线使旧剖面失效，须重新采样或导入。

⌘/Ctrl+Z 撤销，⌘/Ctrl+Shift+Z 重做，⌘/Ctrl+S 保存。会话撤销与长期工程修订是两套机制。

### 3.1 同一工程的多路径与装配（开发版）

打开“工程路径与装配”，关系图左侧是同一工程的规划路径，右侧是独立制造装配。点击路径选择当前编辑对象；地图、RPL、剖面、SLD 和普通费用指标显示活跃路径。全工程制造数量和总费用在此页单独核对，不能把各路线费用直接相加。

复制前填写名称并选择装配关系策略：

- **独立装配**：新路径有新制造实体，实际采购量和装配数量增加；同样的几何也代表另一套实物。
- **备选方案**：与原路线关联同一套实物装配，是互斥方案；制造和采购只计一次，安装费只计明确的安装路线。
- **未绑定**：保留规划路径供对照，暂不计入全工程采购或安装。

选择活跃路径不会自动改变实际安装归属。需采用备选路线时，在关联路径中选择它并点击“明确设为该装配安装路线”，再核对全工程工期与费用。每套实物只能有一条安装路线。

独占装配的柔性路径可正常拖点、改余缆，制造量随核计算更新；固定段仍保持指定量。多条备选共享一套装配时，修改几何而保留实物量可通过校核，改变制造总量、缆型顺序或组件/参考位置则会拒绝。界面保留草稿，可撤销，或明确“为当前草稿建立独立装配”（fork）；后者生成新的实物，旧库存保留且仍计采购。安装主路线分离或移除后仍有备选时，须明确旧装配接替路径。

缆材库、GIS和地形来源库属于整个工程，活跃投影中的编辑会经校核同步给其他路径。删除被库存或其他路径使用的缆型会拒绝。路径的几何、测深、事件、缆长模式和约束保持独立。移除路径默认不删除制造库存；未分配库存仍计一次采购，不计安装或预备费。只有明确删除无关联装配，实物采购量才从工程中移除。

“从单路径 JSON 加入当前工程”用于添加路径，来源须使用当前工程共享缆库、GIS和地形源库；不同资源先明确合并共享资源。当前关联是一条路径对应一套完整装配，不支持自动分割库存或同一实物同时安装两次。开放 schema 2、参数、完整示例和上限见 [WORKSPACE_NOTES.md](WORKSPACE_NOTES.md)。

## 4. RPL、缆长模式与装配

RPL 每行代表点，分段设置属于该点到下一点。设置缆型、表面/海底余缆、柔性/固定模式、埋设和段尾附加缆长；末点没有后续段。

柔性模式保持路线和目标余缆，计算需要的缆长；固定模式保存指定缆长，改变路线后反算余缆。切换固定模式前等待分析完成。固定量不足会显示负余缆。底余缆需有效且覆盖该段的地形，缺测显示“—”。

“电缆与装配”编辑直径、湿重、EA、EI、推荐速度、张力/弯曲限制、单价，并添加中继器或接头。每米价与附件单件价分别计费。`replace` 附属体占用已有实物长度并扣除该跨度缆材；`additional` 额外增加实物长度。常规位置是路线表面 KP；完整 JSON 的 `cable_kp_m` 是实物起始端，有限体终点也须在范围内。

## 5. 导入

“导入”选择文件或粘贴文本，支持 RPL、剖面、XYZ、GeoTIFF、GeoJSON 和完整工程。错误行会提示，至少两个有效路线点才替换路线。RPL 替换会清除旧关联剖面和组件，导入前保存工程可恢复。

RPL 示例：

```csv
label,longitude,latitude,depth_m,note
登陆点,118.0,22.0,30,起点
离岸点,118.2,22.1,180,转折点
```

文本导入支持常见英文/中文列名和度分秒，界面统一十进制度；逗号/引号/换行字段按 CSV 规则加引号。

RPL先“解析预览”，核对源记录、实际行号、经纬度、分段参数和错误，再“应用 RPL 导入”。默认收集错误，有坏记录时不能应用；只有明确选择跳过并重新解析，才可应用有效点。跳过可能把缺失记录两侧直接连接，必须核对桥接警告。语法损坏或非法工程分段不会因选择跳过而成为有效数据。输入、模板或当前工程改变后，旧预览失效。

“定宽 / 多行记录模板”支持每条记录1–32行、头部行、注释、索引起点、字段位置/宽度或分隔列。定宽按Unicode代码点计数，Tab计一个字符；CSV引号中的换行仍属于同一逻辑记录，并保留真实源行范围。填写整体DMS或分开的度/分/秒/半球字段，明确深度正方向、单位、缆型映射和分段属于进入/离开当前点。源表面KP仅用于追溯，不覆盖实际地理距离；累计实物KP差额可形成固定制造长度。默认缆型须是当前库中的实际编号，源名称映射不会再次映射默认编号。

模板可载入、校验、下载JSON并复用；两个内置模板带明确合成源文本。解析报告可完整下载。应用会替换活跃路径及分段，清除旧剖面、组件和制造参考；旧制造域约束须先明确解除，多路径共享库存仍需通过关系校核。格式合同和预算见 [RPL_TEMPLATE_NOTES.md](RPL_TEMPLATE_NOTES.md)。

剖面示例：

```csv
kp_m,depth_m
0,30
10000,180
20000,
30000,600
```

KP 严格递增，以米记录；空水深为缺测，不跨缺测补算。导入绑定当时路线，绑定不能证明测量质量。XYZ 为 `longitude,latitude,depth_m` WGS84 散点；设置沿线采样间距、最大间隙及线性/IDW，默认凸包外不外推。当前散点上限 200,000 点。

GeoTIFF 需要有效 CRS，采样第一波段；明确选择正水深或正高程，填写垂直基准，NoData 保持缺测，上传上限 128 MB。EPSG 不替代潮位/海图深度基准。GeoJSON 使用 WGS84 FeatureCollection；既有海缆层用于穿越，限制区域用于碰撞。开发版完整 JSON 支持旧单路径 schema 1 迁移和同工程多路径 schema 2，包含共享库、全部路径、制造装配与关联；图形文件不承载这些完整关系。

KML 支持点、线、多边形及 MultiGeometry，保留名称/属性/高度，外部 NetworkLink 不下载。高度不直接转换为水深；线几何可以作为路线候选，水深仍需另行提供。Shapefile 以 ZIP 上传同名 `.shp/.dbf` 和可选 `.shx/.prj/.cpg`；`.prj` 缺失时明确输入 `EPSG:xxxx`，DBF 可声明 `gbk` 等编码。多个 Shapefile 需要指定压缩包内源文件名，几何转换为 WGS84。详细格式限制见 `GEODATA_NOTES.md`。

Surfer `.grd` 支持 DSAA 文本、DSBB 二进制和 DSRB 标签网格，须声明源坐标系；选择线性或最近节点、深度正方向、单位和垂直基准。旋转网格暂拒绝，含断层只允许最近节点。XYZ、GeoTIFF、Surfer 可明确选择 m/ft/fathom，转换后内部仍为米，不按数值或后缀猜单位。

### 5.1 共享多源地形

在地形来源库中上传XYZ、GeoTIFF或Surfer，明确源CRS、单位、深度正方向和垂直基准；启用并设置优先级。按优先级降序、同级ID升序逐点选择，缺测或范围外可回退到下一来源，资料损坏、缺最佳基准网格等配置错误会拒绝。默认不同垂直基准不能混采，须明确选择一个同名基准，不能自动潮位转换。

先生成实际沿线剖面预览，核对来源数、逐点来源、回退和缺测，再明确应用。源内容、解释、启用/优先级或删除变化会停用旧剖面；改名或排列不使它失效。源库由所有路径共享，各路径须分别重采样；旧剖面不会用点水深补救。库随完整工程、保存、修订恢复和JSON保留原始资料。每库最多8源、单源8MiB、总解码12MiB/库JSON16MiB，查询最多50,000点；大资料仍可用既有单源导入。边界和优先级不证明测量精度。见 `TERRAIN_SOURCES_NOTES.md`。

## 6. 地形分析

DTM 将 XYZ 构成局部米制网格，计算水深、坡度、坡向、阴影和等深线。设置间距、最大采样间隙、插值、等深线间隔及垂直基准后运行。缺测保留空值，地图颜色/三维来自同一数据。等深线可加入参考图层，不自动替代沿线剖面。

插值可选线性、IDW或“最小曲率”。最小曲率是实际薄板平滑求解；张力作用于去平面趋势后的残差，张力、平滑权重、数据权重与迭代预算会影响结果。先检查收敛、数据残差、有效域与唯一解诊断；未收敛输出不能当作验收地形。无观测锚定的独立区域保留NoData；全部不可用、纯薄板缺少完整单元或仅角点连通等输入会拒绝。该方法最多20,000源点、40,000活动未知节点，不是百万点分块算法，也不保证穿过每个测点。求解容差是LSMR相对停止条件，不是米制最大节点变化。

可用WGS84 Polygon/MultiPolygon GeoJSON裁剪网格，支持标准孔洞与排除区；也可导入BLN并声明源CRS。用于裁剪的简单闭合BLN多边形，0标志保留内部、1标志排除内部；普通切片线的标志不自动排除区域。多个简单BLN对象可用，自接触compound BLN桥连岛环和自交输入会拒绝。栅格按节点保留NoData，亚格孔洞未命中节点时未被差分完整分辨；等深线和切片另核对原多边形。不能把这些缺测用零水深填补。

运行地形后，在切片面板输入经纬度折线或BLN折线，设置沿线站距与双线性/最近节点采样，下载CSV及结果JSON。切片读取完整GeoTIFF而非缩略预览；距离为栅格投影中的折线水平累计量，不是航路椭球KP，另输出水深、坡度和有效段底距。缺测水深保持空白，不跨空档积分，穿过孔洞时整个底距为未知；这条自由折线切片不会自动绑定或替换规划剖面。参数、BLN范围和实际算例见 [DTM_NOTES.md](DTM_NOTES.md)。

导出 GeoTIFF 四波段为水深 m、坡度 degree、坡向 degree、阴影 0-1；NoData −9999。坡向是水深增大方向，0°北、90°东。原始网格最多 250,000 单元，预览最多 128×128，预览不能代表原始分辨率。投影、间距、来源和插值警告随结果输出。

## 7. 工程工具

工具先提供预览、报告和警告，应用后可撤销。同曲线加密保持几何和制造量；测地线转恒向线近似会改变曲线并使旧剖面失效。按深度分缆需有效、无缺测剖面与连续覆盖深度规则，每次阈值穿越均插点。固定段默认保留制造量，显式转换柔性才按余缆重算。

余缆模板按缆型及 KP 范围，固定策略为保留/转换/拒绝。拆分支持点或内部 KP，不能切穿有限刚性体；输出两个独立工程。合并按选中顺序连接，异地端点须明确允许真实连接段及缆型/余缆，不同币种不可合并。反向同步地形、实物跨度、事件和附加量；详细参数见 `TOOLS_NOTES.md`。

路径约束可以设置 Rigid、Clamped、Sliding 以及物理缆里程 Path Link。Rigid 不被求解器自动移动；Clamped 保持相邻刚性点间的相对位置；Sliding 按固定制造量寻找新的位置。显式编辑刚性点仍允许。启用后，位置编辑必须通过约束求解，不能直接改坐标绕过制造域。固定量不足会报告；结构变换尚不支持保留约束时，需要先明确清除约束再操作。详细合同见 `CONSTRAINT_NOTES.md`。

制造装配 CSV 可预览后替换制造清单，或按实物 KP 添加占用既有缆材的附件。替换必须明确接受“总实物量按路线表面比例映射”，地图曲线保持，分段变为固定制造量；这不是测得的海底定位。清单支持电缆、附加量、附件和零长度参考点，参考点不增加缆长或费用。已有 Path Link 必须先清除；制造清单可再次导出。详细列名、单位和限制见 `ASSEMBLY_NOTES.md`。

路由搜索使用有限网格 A*，可设置避让区、带权区域、既有电缆和地形限制，并保留指定经过点。候选先预览再应用，不承诺全局最优。新曲线没有二维地形来源时，其旧剖面会失效；保留制造量时按新的路线反算余缆。参数和工作量上限见 `ROUTING_NOTES.md`。

“实敷调查”输入按敷设顺序排列的 WGS84 测点 CSV/JSON，分别填写观测水深、实物缆 KP 和数据空档。结果给出最近规划 KP、右侧为正的横偏、观测长度与余缆；回环匹配有歧义时不强行对账。只有明确水深基准已对齐，才计算水深差；绝对实物缆 KP 比对另需明确偏移量。船位轨迹不能当作海底缆位。测量线和残差可加入参考图层，原设计保留。详细合同见 `SURVEY_NOTES.md`。

## 8. 成本、审查、保存

成本设置币种、船舶日费、埋设价和预备费。缆材按有效量价，附件单独计件；初步工期按推荐船速加停时。示例费率不是市场报价，未默加税费或汇率。初步工期不等于真实安装计划。

底部“审查提示”检查坡度、余缆、缺测/失效、穿越和限制区。没有发现问题只表示有数据且已配置的规则通过，不证明未配置专项安全。

保存创建完整修订，打开选择本地工程；恢复历史创建新修订并保留旧历史。开发版的保存和恢复覆盖整个工作区，包括全部路径、共享资源、库存和关联，路径没有另一个独立修订号。活跃路径草稿须先通过关系校核；尚未校核或被拒绝的草稿不能当作已保存制造关系。多窗口同时编辑可能触发版本冲突，重新打开最新状态后继续。备份关闭服务后复制 `.oceanroute` 文件夹；运行时可能有 SQLite WAL，不能只复制主文件。完整工作区 JSON 也可备份。

完整工程 JSON 导入创建新的本地工程 ID，保留来源 ID 供追溯。覆盖已经保存的工程必须带当前修订号；没有修订号或使用旧号会拒绝保存，避免覆盖另一个窗口的工作。

旧 schema 1 文件及旧本地单路径工程在开发版打开时迁移为新的 schema 2 工作区，不覆盖原工程，也不沿用旧修订号；原路线、制造量和已绑定剖面保留工程含义。schema 2 文件导入同样创建新工程身份，同时保留内部路径/装配关系。顶层“完整工程 JSON”导出包含整个工作区；RPL、SLD、KML 等普通导出仍针对活跃路径。完整关系通过 `/api/workspace/import`、`/api/workspace/export` 和 `/api/workspaces` 管理，合同见 [WORKSPACE_NOTES.md](WORKSPACE_NOTES.md)。

## 9. 力学与施工计划

“敷设仿真”包含解析悬链线、三维稳态、动态敷设、静态悬空段。填写实际物性/工况，运行后看求解器实际节点、时间帧、张力/触底/曲率/反力与数值诊断。

悬链线适用于均匀正湿重、无流、平海底；稳态包含法向流阻；动态有惯性、材料节点、EA 约束、阻力和接触，支持速度/航向/放缆变化与升沉。输出帧间隔与内部积分步长分开，增加显示帧数不自动提升精度。有限体和混合材料按明确材料坐标配置；分布载荷不等同完整刚体六自由度。悬空段为小斜率静态模型，不包括完整疲劳分析。

动态求解是最老海床端固定的局部窗口，尚非整条航程的移动窗口。初态来自均匀无流悬链线，加入混合材料/实体后可能出现启动过渡；只有明确预备的计划窗口才带制造映射，普通仿真配置不从项目KP猜材料坐标。摩擦使用重量近似，不能当作准确拖底反力。

施工计划按当前缆型、有效深度和目标底张力生成初始船舶/放缆指令、地图与 CSV；需要后续动态和现场校核。Look Ahead 从共同初始条件或完整仿真断点运行真实分支。实船数据只有动画节点时不能恢复完整状态。目标张力搜索在指定范围反复求解，列出候选、误差、失败与是否达到目标；不把数值失败显示成功。

所有 Pro 类模型当前为研究实现，没有原厂或海试对照，不作为已认证现场控制指令。方程、参数和验证范围见 `MODEL_NOTES.md` 与 `SHIPPLAN_NOTES.md`。

动态结果可导出完整 checkpoint JSON，并从保存点继续或做共同断点的 Look Ahead。保存状态包含位置、速度、材料、物性、接触、边界及命令时基，不从动画帧反猜。续算时长是断点后的新增时长，新增船令时刻相对该断点；默认保留保存工况。只可改变允许的未来船速、放缆、海流或运动指令；原材料/海床/求解网格等改变会拒绝。输出仍为累计绝对时间，同时区分历史累计和本次区间指标。摘要仅校验完整性，不是工程认证。详细续算合同见模型说明第8节。

海况研究支持规则波、PM/JONSWAP 随机波谱和用户提供的垂向 RAO 频率表。RAO 是指定船舶的输入数据，界面初始表是研究示例；缺表时必须明确固定升沉才可模拟。生成的运动时序可驱动实际动态求解，可选择有限水深 Airy 波速度参与法向流阻。Monte Carlo 按声明 seed 可复现地抽样，波相位变化可选；分位数仅统计收敛试验，需检查失败数，不能当实船风险概率。当前没有完整六自由度船舶响应、流体惯性载荷或疲劳寿命计算；配置见 `SEA_NOTES.md`。

“回收 / 拖曳 / 浮标”提供四种研究工具：静水均匀缆回收快照、含法向阻力的稳态拖索、条件已着底的抓钩绳长、圆柱浮标静水选型。回收量表示输入的悬空长度减已回收长度，不是自动预测整条缆回收过程。查看实际缆形、端力、平衡残差和可用绳不足提示。浮标按端力垂向分量选排水量，水平不平衡另行报告，不能把总张力直接当浮力。这些结果没有钩挂动力、施工控制或浮标六自由度响应；见 `REPAIR_NOTES.md`。

### 9.1 应答器位置与海流估计（开发版）

在“敷设仿真”选择“应答器 / 海流估计”。“应答器位置预测”使用指定的均匀东/北向海流和真实稳态缆形计算缆上位置；“水平海流估计”用用户观测反推共同的两个海流分量。这是独立批次研究，不会把估计自动写入设计路径或船载控制。

先填写已知水深、正湿重 N/m、直径 m、底部水平牵引 N 和节点数。参考系必须声明 `local_enu` 及 WGS84 原点；所有船位和应答器位置是共同原点下 `[东,北,上]` 米制坐标，Z 向上。软件不自动把经纬度、声学仪器坐标或不同基准转成 ENU。船端 Z 必须在声明的平均海面；该模型只支持均匀、全浸水、不可伸长的柔性缆和平海床。

在 JSON 输入或上传 1–8 条独立稳态记录：每条有 id、船位、已知船速和艏向，观测使用 `arc_from_vessel_m`（从船端向下的悬垂缆弧长）或 `material_m` 与该记录的 `top_material_m`。不能把路线 KP 填成悬垂弧长；超出候选悬垂段会拒绝而不外推。time_s 只是记录标签，不表示已完成动态时序滤波。

预测填写 `current_m_s=[east,north]`；估计填写初猜和海流上下界，并为每个观测提供 `position_m=[x,y,z]`，缺测分量可为 null。估计还必须给绝对标准差 `sigma_m=[sx,sy,sz]` 或 3×3 对称正定 `covariance_m2`，二者不能同时给；标准差单位 m，协方差单位 m²。“由当前预测生成明确合成观测”只生成模型合成样例，不能标记成现场声学测量。

运行后核查实际缆节点、预测/观测点、逐轴残差、马氏距离、异常记录和求解预算。估计的 `summary.estimate_accepted` 与 `solver.converged` 分开：只有优化收敛、两分量局部可辨识、差分敏感度稳定、无活动边界且残差符合声明误差时，才显示“估计已接受”。未接受候选仍可审查 best-fit 几何，但海流协方差/标准差为空。接受后的 2×2 协方差单位为 (m/s)²，形式不确定度只传播给定测量噪声，不包含缆参数、船位、测深或模型偏差。

结果可以下载，输入改变后旧结果有提示。每记录最多 64 个应答器、合计最多 256，输入 JSON 上限 2 MB；优化、真实稳态求解和 ODE 评价另有明确预算。HTTP 为 `POST /api/seismic/predict` 或 `/api/seismic/estimate`，请求 `{config}`。当前不提供实时 Kalman、强制缆形穿过测点、分层/时变流反演、仪器通信、OBC 全程回收或实船精度认证；完整输入与可复算案例见 [SEISMIC_NOTES.md](SEISMIC_NOTES.md)。

### 9.2 长时连续计算与后台任务

打开“长时连续计算”面板，先用明确标为合成的平床例子熟悉流程，或填写自己的JSON物性、船速、放缆、海流与数值配置。普通JSON输入是局部米制场和实际材料参数；例子的长度和深度不代表当前规划工程。使用活跃规划路径时，按下面的预备流程明确生成映射。

提交后后台计算，任务列表显示真实已算时间、活动节点和累计放缆。查看实际轨迹、三维节点、张力与材料平衡；粗化审计显示每次转移、内部步稳定证据及完整材料位置/速度误差。合并条件不满足时保留原网格，记录为0也是实际结果，不自动降低标准。

“完成”只表示到达本次请求时长。“停止”表示节点、工作量或审计上限，只计算了部分；失败给出具体原因。取消在完整chunk后落盘，可下载真实checkpoint，并用“继续计算”创建子任务从该绝对时间继续。没有checkpoint的零进展任务不能恢复。重启会重建真正落盘的进度；已有开发试验断点若模型方法不兼容，须重新计算，不把它当成当前模型状态。

最终结果与checkpoint均可下载JSON。后台数据保存在 `.oceanroute/voyage_jobs`；同一目录只允许一个服务写入。默认至多四个运行/排队任务、250个保存任务和1GB数据缓存；达到上限须清理已结束任务，不能靠换端口同时写同目录。完整API支持删除已结束任务，不影响规划工程。

这仍是有明确适用条件的研究模型。平床、无流1800秒算例已完成1080m放缆，但没有独立细网格全程或海试精度证据；非平床/实体/弯曲/横流等情况可能无法粗化并在容量处停止。参数、错误、工作量和物理限制见 [VOYAGE_NOTES.md](VOYAGE_NOTES.md)。

### 9.3 从活跃工程预备施工窗口

展开“从活跃工程预备制造里程与作业指令窗口”，填写窗口时长、底张力、计划采样间距及允许的数值/环境参数，点击“预备并审查计划窗口”。必须有有效、完整、定深平床数据，缆库明确湿重、直径、EA；初始悬垂库存须同物性。不同深度、缺物性、有限长实体或超出制造库存会拒绝，不静默替换为演示工况。

预览分别显示路线KP、船端制造位置、源计划/局部时间、投影船位和新增放缆。默认开始时刻为源计划已经具备初始悬垂库存的时刻；此前材料作为初态库存，不再放出，也不表示此前施工过程已经算过。初态为零速度解析悬链线，实际初始锚与计划触地点可能有偏差，界面显示这个真实差值，不能用强行移动锚点隐藏。

核对初态偏差、警告和逐段库存后，点击“应用预备窗口到任务配置”，再提交后台任务。完整 `plan_mapping` 必须保留，工程或参数变化后重新预备。结果和检查点带同一映射，恢复可在已预备时间窗内继续；提供非空工程时必须匹配保存摘要，空工程离线恢复仅采用保存快照。超过窗口终点会拒绝，不能用末尾零放缆当作未来施工计划。合同及真实材料守恒验证见 [PLAN_VOYAGE_NOTES.md](PLAN_VOYAGE_NOTES.md)。

### 9.4 变化二维海底

动态敷设可提供真实 `seabed_grid`：X/Y局部米制轴升序、二维z相对于模型海面0向上、缺测null、明确来源和原点（vertical_datum记录来源，不自动换基准）；最多10,000节点。三维视图读取完整二维数据，接触使用单元双线性坡法向，结果报告法向/切向冲量、残差、摩擦耗散和材料守恒。不得把一条剖面横向铺开当作二维测深。

来源库可生成局部动力网格：明确WGS84原点、米制范围、行列数、选用基准和海面相对该基准的高度h；实际 `z_model=-depth-h`，不自动算潮位。先核对来源及缺测再下载/应用。不能形成已知接触单元、原点缺测或坡度超限时返回真实网格和不可应用原因；未来缆/船任何点出域或接触单元缺角会拒绝。详细合同见 `TERRAIN_BATHYMETRY_NOTES.md`。

二维初态仍由水平触底解析形状近似后作法向投影，不是斜床稳态解；静态/跨距以及任何网格与Airy流体波浪组合明确拒绝；船端升沉序列仍可使用。新检查点版本2完整保存网格和接触状态，旧版本仍可恢复；二维床不进行旧平床粗化，预算不足如实停止。制造到施工的自动预备窗口仍只支持平床，不能直接改选项推断变深映射。正常力为末内部步冲量除以该步长；高EA放缆瞬态张力和冲击峰值须另验步长收敛，残差通过不认证工程载荷。完整限制见 `BATHYMETRY_NOTES.md`。

## 10. 导出与故障处理

导出 RPL CSV、KML、GeoJSON、局部米制 DXF、SLD SVG、可打印 HTML 报告、完整 JSON 和制造装配 CSV。HTML 可用浏览器打印 PDF。开发版普通图形/清单导出针对活跃路径，完整 JSON 导出整个 schema 2 工作区。DXF 用于图形交换，不含完整工程语义；完整往返用 OceanRoute JSON，不能改后缀冒充原生格式。

“—”检查地形缺测、剖面失效、范围或零長段。导入失败检查列名/单位/坐标/缆型。动态警告检查物性、边界、内部步长和网格收敛；启动失败检查 Python、依赖安装和端口。保留完整工程、配置、版本和结果以复现偏差。

原厂专有文件、船载接口和完整维修专项尚未兼容；完整范围见 `IMPLEMENTATION_STATUS.md`。Token 费用由平台结算，助手不能接受转账。
