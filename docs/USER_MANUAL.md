# OceanRoute 用户手册


版本 0.6 / 2026-10-04 / 独立海缆规划与敷设研究软件

本文保留既有规划、地形、制造与研究计算流程，补入0.6的投影画布实际编辑、明确定端平衡动态初态、静力输入转动态草稿、地理计划制造映射及完整恢复。历史0.1至0.5发行物独立保留，不由本手册更新覆盖。

发行环境、实际验收和产物记录见 [RELEASE_NOTES.md](RELEASE_NOTES.md)。测试通过不是原厂数值或现场精度等效证据。原厂专有格式、设备接口和完整施工功能仍未兼容；所有标为研究模型的计算须按声明范围使用。

## 1. 安装和启动

安装 Python 3.10 或更高版本，将交付包解压到可写目录。macOS/Linux 执行 `python3 launcher.py`，Windows 执行 `py launcher.py`。启动器创建 `.venv` 并安装依赖，首次安装需要联网；完成后浏览器打开 `http://127.0.0.1:8765`。按 Ctrl+C 结束服务。源码环境也可依 README 分别安装 Python 依赖和编译前端；已编译发布包不需要 Node.js。

实际验收环境为macOS、Python 3.13.9和Chrome；Windows/Linux命令是启动流程支持，不表示已在这些平台完成验收。这是需要Python环境的本机浏览器应用，不是免Python的原生桌面软件。

端口被占用时，在启动器命令后增加 `--port 8766`。默认只监听本机，工程不上传至 Makai 网站。初次打开显示合成演示工程，水深、物性和价格都是示例，不能用于真实决策。“新建”得到两点空白工程，填写实际位置、缆材库、测深和费率后再规划。交付包 `examples/` 提供完整短路线、制造清单及工况合成示例。

## 2. 坐标、单位与三种里程

路线使用 WGS84 十进制度，东经/北纬为正。长度和水深为米，力为 N；缆段单位长度湿重为 N/m、质量为 kg/m，附属体/浮标总质量为 kg、净湿重为 N。时间和价格按字段明确标注。界面 KP 可显示 km，标注 m 的输入仍须填米。水深向下为正；未知保留空白，不能用 0 代替。模拟局部三维坐标的 z 轴向上，与水深符号相反。

路线 KP 沿地理曲线累计；海底距离沿有效 KP-水深剖面累计；电缆 KP 沿实物装配累计。附加缆长和附属体会使三者不同。SLD 是实物缆单线图，不是地图路线。余缆输入 `1.5` 表示 1.5%；表面余缆为 `100×(缆长/平面距离−1)`，底余缆为 `100×(缆长/底距−1)`，负值表示缆量不足。

投影坐标在点资料或工程工具中编辑：明确源EPSG/WKT、X/Y和原生单位，先真实转换预览，再明确应用；可把当前WGS84坐标反转换到源坐标系核对。全部点成功才开放应用，基准最佳网格缺失时拒绝，适用区外显示警告。修改输入或工程后旧预览失效。已有制造域的点须经约束求解，不能绕过固定滑动点或库存校核。深度不随水平转换变更。地图显示投影是另一个选择，步骤见3.2；原厂CSF仍未兼容。详细编辑合同见 `COORDINATE_NOTES.md`。

## 3. 建立与编辑路线

“路由工作空间”包含地图、选中点资料及剖面/SLD/RPL。点击地图点或表格行选择点，拖动改变位置；在点资料或“路由位置表”准确输入名称、经纬度、水深和备注。添加点可在选中位置后插点或在地图追加点。至少保留两个点。

“工程设置”选择恒向线或 WGS84 测地线。地图显示加密后的实际曲线，日期变更线输出分段处理。默认离线经纬网；开启 OpenStreetMap 才需网络。修改位置后重新计算，等待状态栏“计算完成”再固定缆长或导出。移动路线使旧剖面失效，须重新采样或导入。

⌘/Ctrl+Z 撤销，⌘/Ctrl+Shift+Z 重做，⌘/Ctrl+S 保存。会话撤销与长期工程修订是两套机制。

### 3.1 同一工程的多路径与装配

打开“工程路径与装配”，关系图左侧是同一工程的规划路径，右侧是独立制造装配。点击路径选择当前编辑对象；地图、RPL、剖面、SLD 和普通费用指标显示活跃路径。全工程制造数量和总费用在此页单独核对，不能把各路线费用直接相加。

复制前填写名称并选择装配关系策略：

- **独立装配**：新路径有新制造实体，实际采购量和装配数量增加；同样的几何也代表另一套实物。
- **备选方案**：与原路线关联同一套实物装配，是互斥方案；制造和采购只计一次，安装费只计明确的安装路线。
- **未绑定**：保留规划路径供对照，暂不计入全工程采购或安装。

选择活跃路径不会自动改变实际安装归属。需采用备选路线时，在关联路径中选择它并点击“明确设为该装配安装路线”，再核对全工程工期与费用。每套实物只能有一条安装路线。

独占装配的柔性路径可正常拖点、改余缆，制造量随核计算更新；固定段仍保持指定量。多条备选共享一套装配时，修改几何而保留实物量可通过校核，改变制造总量、缆型顺序或组件/参考位置则会拒绝。界面保留草稿，可撤销，或明确“为当前草稿建立独立装配”（fork）；后者生成新的实物，旧库存保留且仍计采购。安装主路线分离或移除后仍有备选时，须明确旧装配接替路径。

缆材库、GIS和地形来源库属于整个工程，活跃投影中的编辑会经校核同步给其他路径。删除被库存或其他路径使用的缆型会拒绝。路径的几何、测深、事件、缆长模式和约束保持独立。移除路径默认不删除制造库存；未分配库存仍计一次采购，不计安装或预备费。只有明确删除无关联装配，实物采购量才从工程中移除。

“从单路径 JSON 加入当前工程”用于添加路径，来源须使用当前工程共享缆库、GIS和地形源库；不同资源先明确合并共享资源。当前关联是一条路径对应一套完整装配，不支持自动分割库存或同一实物同时安装两次。开放 schema 2、参数、完整示例和上限见 [WORKSPACE_NOTES.md](WORKSPACE_NOTES.md)。

### 3.2 投影地图与空白工程

地图在“经纬地图”和“投影视图”之间切换。投影视图填写“地图显示 CRS”，点击“计算真实投影视图”；成功后直接显示，核对实际转换操作、原生轴单位、适用区和缺最佳基准网格的诊断。路线、点位、GIS和地形轮廓均由真实转换坐标绘制，刻度不是替换经纬度文字；原生英尺坐标也须按其单位阅读。源路线仍保存WGS84；只切换显示不会改变路线、制造库存或地形绑定。在线底图只用于经纬地图。

等待活跃路线“计算完成”后，投影画布可直接编辑该路径：

1. 选择“选取 / 拖动”，拖动点并释放。软件按当前显示CRS的原生X/Y真实反算WGS84，再通过制造域求解；结果同时列出目标X/Y、实际约束后X/Y和最终经纬度。Clamped点的实际位置可能与鼠标目标不同，以求解结果为准。
2. 点击“追加点”，填写新点名称，明确选择当前共享库缆型和柔性/固定新段，再点击画布背景。固定新段须填写非负制造缆长，空值不能补零；新点水深保持未测量。此入口追加至末端，不在已有段内自动切分材料。
3. 选中点后点击“删除点”。至少保留两点；内部点删除会合并相邻段。相邻缆型、余缆、埋设或其他分段信息冲突时拒绝，不能借删点丢失材料信息。固定量按已声明数量求和；混合固定/柔性段须有当前有效分析，才可用实际柔性缆量合并。明确附加量、停时和费用同时保留。

制造域启用时，Rigid可由用户明确拖动，Clamped经锚线求解；Fixed Sliding锁定任意X/Y移动，改位置须使用原实物KP入口。结构增删须先在约束页明确“解除旧域”，不能自动清掉Path Link。每次成功提交只建立一次完整工程撤销；共享材料、地形、库存、其他路径和未知扩展字段仍随工作区保留，不自动fork。

输入、CRS、活跃路径、工程草稿或修订改变后，迟到转换结果丢弃；失败不应用旧候选。成功后地图保留视窗并按新真实路线重投影。底余缆草稿因旧剖面失效而无法保存时，保留草稿，可按5.2联合重采样再校核。共享制造分歧或保存版本冲突仍拒绝，不覆盖另一窗口。也可继续使用点资料的显式X/Y预览工具或经纬地图。

路线跨日期线时按实际曲线分段；自定义投影的适用区、尺度和边界不能由图形外观推断。投影画布平移/缩放不改变数据；在线瓦片和栅格底图未重投影。纯显示转换合同见 `MAP_PROJECTION_NOTES.md`；实际点位编辑的开发记录见 [DEVELOPMENT_0.6.md](DEVELOPMENT_0.6.md)。

完整工作区可以暂时没有路径。此时可查看关系、费用总账及共享资源，未分配库存仍计采购；路线位置表、SLD和剖面标签暂不出现。通过新增入口添加路径后再编辑，界面不会自动塞入演示路径。

## 4. RPL、缆长模式与装配

RPL 每行代表点，分段设置属于该点到下一点。设置缆型、表面/海底余缆、柔性/固定模式、埋设和段尾附加缆长；末点没有后续段。

柔性模式保持路线和目标余缆，计算需要的缆长；固定模式保存指定缆长，改变路线后反算余缆。切换固定模式前等待分析完成。固定量不足会显示负余缆。底余缆需有效且覆盖该段的地形，缺测显示“—”。

“电缆与装配”编辑直径、湿重、EA、EI、推荐速度、张力/弯曲限制、单价，并添加中继器或接头。每米价与附件单件价分别计费。`replace` 附属体占用已有实物长度并扣除该跨度缆材；`additional` 额外增加实物长度。常规位置是路线表面 KP；完整 JSON 的 `cable_kp_m` 是实物起始端，有限体终点也须在范围内。

## 5. 导入

“导入”选择文件或粘贴文本，支持 RPL、剖面、XYZ、GeoTIFF、GeoJSON 和完整工程。错误行会提示，至少两个有效路线点才替换路线。RPL 替换会清除旧关联剖面和组件，导入前保存工程可恢复。

RPL 示例：

```csv
label,longitude,latitude,depth_m,note
登陆点,118.0,22.0,30,起点
离岸点,118.2,22.1,180,转折点
```

文本导入支持常见英文/中文列名和度分秒，界面统一十进制度；逗号/引号/换行字段按 CSV 规则加引号。

RPL先“解析预览”，核对源记录、实际行号、经纬度、分段参数和错误，再“应用 RPL 导入”。默认收集错误，有坏记录时不能应用；只有明确选择跳过并重新解析，才可应用有效点。跳过可能把缺失记录两侧直接连接，必须核对桥接警告。语法损坏或非法工程分段不会因选择跳过而成为有效数据。输入、模板或当前工程改变后，旧预览失效。

“定宽 / 多行记录模板”支持每条记录1–32行、头部行、注释、索引起点、字段位置/宽度或分隔列。定宽按Unicode代码点计数，Tab计一个字符；CSV引号中的换行仍属于同一逻辑记录，并保留真实源行范围。填写整体DMS或分开的度/分/秒/半球字段，明确深度正方向、单位、缆型映射和分段属于进入/离开当前点。源表面KP仅用于追溯，不覆盖实际地理距离；累计实物KP差额可形成固定制造长度。默认缆型须是当前库中的实际编号，源名称映射不会再次映射默认编号。

模板可载入、校验、下载JSON并复用；两个内置模板带明确合成源文本。解析报告可完整下载。应用会替换活跃路径及分段，清除旧剖面、组件和制造参考；旧制造域约束须先明确解除，多路径共享库存仍需通过关系校核。格式合同和预算见 [RPL_TEMPLATE_NOTES.md](RPL_TEMPLATE_NOTES.md)。

剖面示例：

```csv
kp_m,depth_m
0,30
10000,180
20000,
30000,600
```

KP 严格递增，以米记录；空水深为缺测，不跨缺测补算。导入绑定当时路线，绑定不能证明测量质量。XYZ 为 `longitude,latitude,depth_m` WGS84 散点；设置沿线采样间距、最大间隙及线性/IDW，默认凸包外不外推。当前散点上限 200,000 点。

GeoTIFF 需要有效 CRS，采样第一波段；明确选择正水深或正高程，填写垂直基准，NoData 保持缺测，上传上限 128 MB。EPSG 不替代潮位/海图深度基准。GeoJSON 使用 WGS84 FeatureCollection；既有海缆层用于穿越，限制区域用于碰撞。完整 JSON 支持旧单路径 schema 1 迁移和同工程多路径 schema 2，包含共享库、全部路径、制造装配与关联；图形文件不承载这些完整关系。

KML 支持点、线、多边形及 MultiGeometry，保留名称/属性/高度，外部 NetworkLink 不下载。高度不直接转换为水深；线几何可以作为路线候选，水深仍需另行提供。Shapefile 以 ZIP 上传同名 `.shp/.dbf` 和可选 `.shx/.prj/.cpg`；`.prj` 缺失时明确输入 `EPSG:xxxx`，DBF 可声明 `gbk` 等编码。多个 Shapefile 需要指定压缩包内源文件名，几何转换为 WGS84。详细格式限制见 `GEODATA_NOTES.md`。

Surfer `.grd` 支持 DSAA 文本、DSBB 二进制和 DSRB 标签网格，须声明源坐标系；选择线性或最近节点、深度正方向、单位和垂直基准。旋转网格暂拒绝，含断层只允许最近节点。XYZ、GeoTIFF、Surfer 可明确选择 m/ft/fathom，转换后内部仍为米，不按数值或后缀猜单位。

### 5.1 共享多源地形

在地形来源库中上传XYZ、GeoTIFF或Surfer，明确源CRS、单位、深度正方向和垂直基准；启用并设置优先级。按优先级降序、同级ID升序逐点选择，缺测或范围外可回退到下一来源，资料损坏、缺最佳基准网格等配置错误会拒绝。默认不同垂直基准不能混采，须明确选择一个同名基准，不能自动潮位转换。

先生成实际沿线剖面预览，核对来源数、逐点来源、回退和缺测，再明确应用。源内容、解释、启用/优先级或删除变化会停用旧剖面；改名或排列不使它失效。源库由所有路径共享，可分别重采样，或按5.2一次明确更新多条路径；旧剖面不会用点水深补救。库随完整工程、保存、修订恢复和JSON保留原始资料。每库最多8源、单源8MiB、总解码12MiB/库JSON16MiB，查询最多50,000点；大资料仍可用既有单源导入。边界和优先级不证明测量精度。见 `TERRAIN_SOURCES_NOTES.md`。

### 5.2 整工程地形更新

打开“工程工具”→“多源测深库”→“工作区多路线原子重采样”。修改独立来源草稿后直接预览整工程，不先单独应用新源库。选择明确的垂直基准、采样间距和要更新的路径，在“明确计算预算”中设置最多站点等上限。逐条核对真实源查询、回退、缺测、底距、缆长及制造关系诊断。来源库摘要变化时，来源绑定剖面及柔性底余缆路径全部必选；遗漏时整笔拒绝，不能让未选择路径沿用已失效地形。

只有全部目标通过，才可以应用整工程候选。任一路径采样或共享装配校核失败，整批不应用。柔性底余缆可能改变制造量：默认允许独占装配更新，共享实物则必须全部关联路径所需缆型、顺序、量及组件/参考位置一致，才统一更新库存一次；分歧拒绝，不自动生成独立装配。选择保留库存政策时，制造量变化也拒绝。库、路线、选择或参数改变后旧预览失效，重新计算再应用。应用支持整工程撤销；保存仍创建整个工作区修订。该流程不自动合并垂直基准或替缺测补零，详见 `WORKSPACE_TERRAIN_NOTES.md`。

投影拖点等操作留下尚未验收的路线草稿时，可将该草稿与新来源一起预览：先保留当前编辑，再进入此流程，逐路径核对新剖面和制造诊断。候选必须是完整工作区；固定制造域、共享装配或缺测检查失败时，不能只应用其中已成功的路径。编辑备注、几何、来源或修订等任何相关输入后，须重新预览，不使用旧候选保存。

## 6. 地形分析

DTM 将 XYZ 构成局部米制网格，计算水深、坡度、坡向、阴影和等深线。设置间距、最大采样间隙、插值、等深线间隔及垂直基准后运行。缺测保留空值，地图颜色/三维来自同一数据。等深线可加入参考图层，不自动替代沿线剖面。

插值可选线性、IDW或“最小曲率”。最小曲率是实际薄板平滑求解；张力作用于去平面趋势后的残差，张力、平滑权重、数据权重与迭代预算会影响结果。先检查收敛、数据残差、有效域与唯一解诊断；未收敛输出不能当作验收地形。无观测锚定的独立区域保留NoData；全部不可用、纯薄板缺少完整单元或仅角点连通等输入会拒绝。该方法最多20,000源点、40,000活动未知节点，不是百万点分块算法，也不保证穿过每个测点。求解容差是LSMR相对停止条件，不是米制最大节点变化。

可用WGS84 Polygon/MultiPolygon GeoJSON裁剪网格，支持标准孔洞与排除区；也可导入BLN并声明源CRS。用于裁剪的简单闭合BLN多边形，0标志保留内部、1标志排除内部；普通切片线的标志不自动排除区域。多个简单BLN对象可用，自接触compound BLN桥连岛环和自交输入会拒绝。栅格按节点保留NoData，亚格孔洞未命中节点时未被差分完整分辨；等深线和切片另核对原多边形。不能把这些缺测用零水深填补。

运行地形后，在切片面板输入经纬度折线或BLN折线，设置沿线站距与双线性/最近节点采样，下载CSV及结果JSON。切片读取完整GeoTIFF而非缩略预览；距离为栅格投影中的折线水平累计量，不是航路椭球KP，另输出水深、坡度和有效段底距。缺测水深保持空白，不跨空档积分，穿过孔洞时整个底距为未知；这条自由折线切片不会自动绑定或替换规划剖面。参数、BLN范围和实际算例见 [DTM_NOTES.md](DTM_NOTES.md)。

导出 GeoTIFF 四波段为水深 m、坡度 degree、坡向 degree、阴影 0-1；NoData −9999。坡向是水深增大方向，0°北、90°东。原始网格最多 250,000 单元，预览最多 128×128，预览不能代表原始分辨率。投影、间距、来源和插值警告随结果输出。

## 7. 工程工具

工具先提供预览、报告和警告，应用后可撤销。同曲线加密保持几何和制造量；测地线转恒向线近似会改变曲线并使旧剖面失效。按深度分缆需有效、无缺测剖面与连续覆盖深度规则，每次阈值穿越均插点。固定段默认保留制造量，显式转换柔性才按余缆重算。

余缆模板按缆型及 KP 范围，固定策略为保留/转换/拒绝。拆分支持点或内部 KP，不能切穿有限刚性体；输出两个独立工程。合并按选中顺序连接，异地端点须明确允许真实连接段及缆型/余缆，不同币种不可合并。反向同步地形、实物跨度、事件和附加量；详细参数见 `TOOLS_NOTES.md`。

路径约束可以设置 Rigid、Clamped、Sliding 以及物理缆里程 Path Link。Rigid 不被求解器自动移动；Clamped 保持相邻刚性点间的相对位置；Sliding 按固定制造量寻找新的位置。显式编辑刚性点仍允许。启用后，位置编辑必须通过约束求解，不能直接改坐标绕过制造域。固定量不足会报告；结构变换尚不支持保留约束时，需要先明确清除约束再操作。详细合同见 `CONSTRAINT_NOTES.md`。

制造装配 CSV 可预览后替换制造清单，或按实物 KP 添加占用既有缆材的附件。替换必须明确接受“总实物量按路线表面比例映射”，地图曲线保持，分段变为固定制造量；这不是测得的海底定位。清单支持电缆、附加量、附件和零长度参考点，参考点不增加缆长或费用。已有 Path Link 必须先清除；制造清单可再次导出。详细列名、单位和限制见 `ASSEMBLY_NOTES.md`。

路由搜索使用有限网格 A*，可设置避让区、带权区域、既有电缆和地形限制，并保留指定经过点。候选先预览再应用，不承诺全局最优。新曲线没有二维地形来源时，其旧剖面会失效；保留制造量时按新的路线反算余缆。参数和工作量上限见 `ROUTING_NOTES.md`。

“实敷调查”输入按敷设顺序排列的 WGS84 测点 CSV/JSON，分别填写观测水深、实物缆 KP 和数据空档。结果给出最近规划 KP、右侧为正的横偏、观测长度与余缆；回环匹配有歧义时不强行对账。只有明确水深基准已对齐，才计算水深差；绝对实物缆 KP 比对另需明确偏移量。船位轨迹不能当作海底缆位。测量线和残差可加入参考图层，原设计保留。详细合同见 `SURVEY_NOTES.md`。

## 8. 成本、审查、保存

成本设置币种、船舶日费、埋设价和预备费。缆材按有效量价，附件单独计件；初步工期按推荐船速加停时。示例费率不是市场报价，未默加税费或汇率。初步工期不等于真实安装计划。

底部“审查提示”检查坡度、余缆、缺测/失效、穿越和限制区。没有发现问题只表示有数据且已配置的规则通过，不证明未配置专项安全。

保存创建完整修订，打开选择本地工程；恢复历史创建新修订并保留旧历史。保存和恢复覆盖整个工作区，包括全部路径、共享资源、库存和关联，路径没有另一个独立修订号。活跃路径草稿须先通过关系校核；尚未校核或被拒绝的草稿不能当作已保存制造关系。多窗口同时编辑可能触发版本冲突，本窗口草稿保留；先核对并保留所需改动，再打开最新修订继续，不自动合并或强行覆盖。备份关闭服务后复制 `.oceanroute` 文件夹；运行时可能有 SQLite WAL，不能只复制主文件。完整工作区 JSON 也可备份。

完整工程 JSON 导入创建新的本地工程 ID，保留来源 ID 供追溯。覆盖已经保存的工程必须带当前修订号；没有修订号或使用旧号会拒绝保存，避免覆盖另一个窗口的工作。

旧 schema 1 文件及旧本地单路径工程打开时迁移为新的 schema 2 工作区，不覆盖原工程，也不沿用旧修订号；原路线、制造量和已绑定剖面保留工程含义。schema 2 文件导入同样创建新工程身份，同时保留内部路径/装配关系。顶层“完整工程 JSON”导出包含整个工作区；RPL、SLD、KML 等普通导出仍针对活跃路径。完整关系通过 `/api/workspace/import`、`/api/workspace/export` 和 `/api/workspaces` 管理，合同见 [WORKSPACE_NOTES.md](WORKSPACE_NOTES.md)。

## 9. 力学与施工计划

“敷设仿真”包含解析悬链线、三维稳态、动态敷设、静态悬空段。填写实际物性/工况，运行后看求解器实际节点、时间帧、张力/触底/曲率/反力与数值诊断。

悬链线适用于均匀正湿重、无流、平海底；稳态包含法向流阻；动态有惯性、材料节点、EA 约束、阻力和接触，支持速度/航向/放缆变化与升沉。输出帧间隔与内部积分步长分开，增加显示帧数不自动提升精度。有限体和混合材料按明确材料坐标配置；分布载荷不等同完整刚体六自由度。悬空段为小斜率静态模型，不包括完整疲劳分析。

动态求解是最老材料端固定的局部窗口，尚非整条航程的移动窗口。默认初态保留均匀无流悬链线/床面投影近似；也可按9.7明确提供二维定端自然长并实际求平衡。混合材料和实体按制造坐标真实加载，但不能用后续载荷能力证明其初态已经平衡。只有明确预备的计划窗口才带制造映射，普通仿真配置不从项目KP猜材料坐标。原简化平床摩擦与二维床面实际法向冲量方法须区分；都不能据单次数值收敛认定拖底载荷准确。

施工计划按当前缆型、有效深度和目标底张力生成初始船舶/放缆指令、地图与 CSV；需要后续动态和现场校核。Look Ahead 从共同初始条件或完整仿真断点运行真实分支。实船数据只有动画节点时不能恢复完整状态。目标张力搜索在指定范围反复求解，列出候选、误差、失败与是否达到目标；不把数值失败显示成功。

所有 Pro 类模型当前为研究实现，没有原厂或海试对照，不作为已认证现场控制指令。方程、参数和验证范围见 `MODEL_NOTES.md` 与 `SHIPPLAN_NOTES.md`。

动态结果可导出完整 checkpoint JSON，并从保存点继续或做共同断点的 Look Ahead。保存状态包含位置、速度、材料、物性、接触、边界及命令时基，不从动画帧反猜。续算时长是断点后的新增时长，新增船令时刻相对该断点；默认保留保存工况。只可改变允许的未来船速、放缆、海流或运动指令；原材料/海床/求解网格等改变会拒绝。输出仍为累计绝对时间，同时区分历史累计和本次区间指标。摘要仅校验完整性，不是工程认证。详细续算合同见模型说明第8节。

海况研究支持规则波、PM/JONSWAP 随机波谱和用户提供的垂向 RAO 频率表。RAO 是指定船舶的输入数据，界面初始表是研究示例；缺表时必须明确固定升沉才可模拟。生成的运动时序可驱动实际动态求解，可选择有限水深 Airy 波速度参与法向流阻。Monte Carlo 按声明 seed 可复现地抽样，波相位变化可选；分位数仅统计收敛试验，需检查失败数，不能当实船风险概率。当前没有完整六自由度船舶响应、流体惯性载荷或疲劳寿命计算；配置见 `SEA_NOTES.md`。

“回收 / 拖曳 / 浮标”提供四种研究工具：静水均匀缆回收快照、含法向阻力的稳态拖索、条件已着底的抓钩绳长、圆柱浮标静水选型。回收量表示输入的悬空长度减已回收长度，不是自动预测整条缆回收过程。查看实际缆形、端力、平衡残差和可用绳不足提示。浮标按端力垂向分量选排水量，水平不平衡另行报告，不能把总张力直接当浮力。这些结果没有钩挂动力、施工控制或浮标六自由度响应；见 `REPAIR_NOTES.md`。

### 9.1 应答器位置与海流估计

在“敷设仿真”选择“应答器 / 海流估计”。“应答器位置预测”使用指定的均匀东/北向海流和真实稳态缆形计算缆上位置；“水平海流估计”用用户观测反推共同的两个海流分量。这是独立批次研究，不会把估计自动写入设计路径或船载控制。

先填写已知水深、正湿重 N/m、直径 m、底部水平牵引 N 和节点数。参考系必须声明 `local_enu` 及 WGS84 原点；所有船位和应答器位置是共同原点下 `[东,北,上]` 米制坐标，Z 向上。软件不自动把经纬度、声学仪器坐标或不同基准转成 ENU。船端 Z 必须在声明的平均海面；该模型只支持均匀、全浸水、不可伸长的柔性缆和平海床。

在 JSON 输入或上传 1–8 条独立稳态记录：每条有 id、船位、已知船速和艏向，观测使用 `arc_from_vessel_m`（从船端向下的悬垂缆弧长）或 `material_m` 与该记录的 `top_material_m`。不能把路线 KP 填成悬垂弧长；超出候选悬垂段会拒绝而不外推。time_s 只是记录标签，不表示已完成动态时序滤波。

预测填写 `current_m_s=[east,north]`；估计填写初猜和海流上下界，并为每个观测提供 `position_m=[x,y,z]`，缺测分量可为 null。估计还必须给绝对标准差 `sigma_m=[sx,sy,sz]` 或 3×3 对称正定 `covariance_m2`，二者不能同时给；标准差单位 m，协方差单位 m²。“由当前预测生成明确合成观测”只生成模型合成样例，不能标记成现场声学测量。

运行后核查实际缆节点、预测/观测点、逐轴残差、马氏距离、异常记录和求解预算。估计的 `summary.estimate_accepted` 与 `solver.converged` 分开：只有优化收敛、两分量局部可辨识、差分敏感度稳定、无活动边界且残差符合声明误差时，才显示“估计已接受”。未接受候选仍可审查 best-fit 几何，但海流协方差/标准差为空。接受后的 2×2 协方差单位为 (m/s)²，形式不确定度只传播给定测量噪声，不包含缆参数、船位、测深或模型偏差。

结果可以下载，输入改变后旧结果有提示。每记录最多 64 个应答器、合计最多 256，输入 JSON 上限 2 MB；优化、真实稳态求解和 ODE 评价另有明确预算。HTTP 为 `POST /api/seismic/predict` 或 `/api/seismic/estimate`，请求 `{config}`。当前不提供实时 Kalman、强制缆形穿过测点、分层/时变流反演、仪器通信、OBC 全程回收或实船精度认证；完整输入与可复算案例见 [SEISMIC_NOTES.md](SEISMIC_NOTES.md)。

### 9.2 长时连续计算与后台任务

打开“长时连续计算”面板，先用明确标为合成的平床例子熟悉流程，或填写自己的JSON物性、船速、放缆、海流与数值配置。普通JSON输入是局部米制场和实际材料参数；例子的长度和深度不代表当前规划工程。使用活跃规划路径时，按下面的预备流程明确生成映射。

提交后后台计算，任务列表显示真实已算时间、活动节点和累计放缆。查看实际轨迹、三维节点、张力与材料平衡；粗化审计显示每次转移、内部步稳定证据及完整材料位置/速度误差。合并条件不满足时保留原网格，记录为0也是实际结果，不自动降低标准。

“完成”只表示到达本次请求时长。“停止”表示节点、工作量或审计上限，只计算了部分；失败给出具体原因。“请求取消”在完整chunk后落盘，可用“保存最近完整断点”下载真实checkpoint，并用“按当前时长继续为子任务”从该绝对时间继续。没有checkpoint的零进展任务不能恢复。重启会重建真正落盘的进度；已有开发试验断点若模型方法不兼容，须重新计算，不把它当成当前模型状态。

任务ID与保存输入独立于当前工程草稿。取消、恢复或取断点的请求期间改选另一任务，不会被旧响应切回、混入旧帧或触发旧任务的迟到下载；服务器可能已经完成取消或创建子任务，刷新列表后可明确选择该任务查看。断点文件名含实际任务ID，核对ID和父任务关系后再恢复。修改本地JSON不改变已提交任务；子任务按钮只使用当前时长和工作/输出上限，保持保存物性、控制与制造映射。

最终结果与checkpoint均可下载JSON。后台数据保存在 `.oceanroute/voyage_jobs`；同一目录只允许一个服务写入。默认至多四个运行/排队任务、250个保存任务和1GB数据缓存；达到上限须清理已结束任务，不能靠换端口同时写同目录。完整API支持删除已结束任务，不影响规划工程。

这仍是有明确适用条件的研究模型。平床、无流1800秒算例已完成1080m放缆，但没有独立细网格全程或海试精度证据；非平床/实体/弯曲/横流等情况可能无法粗化并在容量处停止。参数、错误、工作量和物理限制见 [VOYAGE_NOTES.md](VOYAGE_NOTES.md)。

### 9.3 从活跃工程预备施工窗口

展开“从活跃工程预备制造里程与作业指令窗口”，先选择“预备窗口初态方法”，填写窗口时长、计划底张力、采样站距及允许的数值/环境参数，再点击“预备并审查计划窗口”。路线测深和制造区段须有效，缆库明确湿重、直径、EA；缺物性、有限长实体或库存不足会拒绝，不替换为演示工况。

- **已知平床 · 解析悬链线**：保留原流程，要求完整已知定深平床及同物性初始悬垂库存。不同深度不能按该方法默认为平床。
- **地理床格 · 实际定端平衡**：在“地理绑定二维床格 JSON”提供完整 `oceanroute.bathymetry.v1`，在“明确地理定端初态 JSON”声明固定锚WGS84、模型Z、船端Z，以及初始自然长或每段自然长。船端XY来自原计划真实窗口开始船位，不由用户另猜。初始活动材料须满足9.7的同湿重/EA、EI=0、无流波和无已部署实体限制。

地理床格必须有真实水平投影CRS、East/North米制轴、来源原点和已对齐模型海面0的高程。LOCAL任意网格、英尺网格或经纬度格须先真实变换，不能只补EPSG标签。软件将锚、全部床格轴和可选节点初值一起平移到计划起始船位原点；高程不改变，不自动转换潮位或垂直基准。节点初值须用原床格局部米坐标，不能填绝对投影E/N。投影单位为米不保证地面比例为1，仍须核对工程坐标系与测深来源。

预览分开显示路线KP、船端制造位置、源计划/局部时间、局部船位和新增放缆。设起点船端制造站K₀、初始自然库存L，最老材料原点为O=K₀−L≥0；初始船端为K₀，初始新放缆为0。L可含床接触部分，不一定全是悬垂缆，更不能在首块再次投入。默认开始时刻选择已有声明库存的计划时刻，此前过程没有被重新模拟。初态是首次命令前零节点速度，不是移动铺设准稳态；实际锚与计划目标偏差保留，不强移锚点消除。

地理平衡分支输出 `plan_mapping` schema2，保留制造、时间、投影重基准、实际床格和初态证据；旧解析分支仍保留原映射。原Ship Plan船位偏移仍是局部平床初估，警告 `PLAN_OFFSETS_REMAIN_FLAT_LOCAL_FIRST_CUT` 表示曲床初态通过不等于后续计划触点跟随已经验证。

核对初态偏差、警告和逐段库存后，点击“应用预备窗口到任务配置”，再提交后台任务。完整 `plan_mapping` 原样保留，工程或参数变化后重新预备。首次实际动力仍从原始边界独立验收；连续恢复不重复放出初始库存。结果和检查点带同一映射，提供非空工程时须匹配保存摘要；空工程离线恢复只用保存快照，不表示采用新工程。超过窗口终点拒绝，不能用末尾零放缆代替未来施工计划。

[geographic-equilibrium-voyage.json](../examples/geographic-equilibrium-voyage.json) 是明确合成、已实际API运行的完整 `{project,config}` 预备请求，不是恢复文件或测深资料。界面使用时先单独导入其中 `project`，分别填入 `config.seabed_grid`、`config.equilibrium_start` 和其余预备参数；不能将整个外层请求作为工作区或checkpoint导入。旧解析窗口合同见 [PLAN_VOYAGE_NOTES.md](PLAN_VOYAGE_NOTES.md)，新地理平衡合同与独立对照见 [PLAN_EQUILIBRIUM_REVIEW.md](PLAN_EQUILIBRIUM_REVIEW.md)。

### 9.4 变化二维海底

动态敷设可提供真实 `seabed_grid`：X/Y局部米制轴升序、二维z相对于模型海面0向上、缺测null、明确来源和原点（vertical_datum记录来源，不自动换基准）；最多10,000节点。三维视图读取完整二维数据，接触使用单元双线性坡法向，结果报告法向/切向冲量、残差、摩擦耗散和材料守恒。不得把一条剖面横向铺开当作二维测深。

来源库可生成局部动力网格：明确WGS84原点、米制范围、行列数、选用基准和海面相对该基准的高度h；实际 `z_model=-depth-h`，不自动算潮位。先核对来源及缺测再下载/应用。不能形成已知接触单元、原点缺测或坡度超限时返回真实网格和不可应用原因；未来缆/船任何点出域或接触单元缺角会拒绝。详细合同见 `TERRAIN_BATHYMETRY_NOTES.md`。

默认二维初态仍由水平解析形状近似后作法向投影，不是斜床稳态解；可按9.7显式选择实际定端自然长平衡。原静态悬空段不接收二维床，网格与Airy流体波浪组合明确拒绝；允许的船端升沉控制仍可使用，不能据此宣称已求初始波浪平衡。二维床静力另见9.5，不自动替换动态初态；地理计划的显式变深分支见9.3。

旧二维检查点schema2完整保存原网格和接触状态；新定端平衡路径使用schema3及原始平衡证据，两者按各自模型恢复，不静默升级或删证据降级。新明确定端路径无实际床接触时，触地点和底张力为null，图中不假标触点；灰色固定支持点与触地位置分开。旧近似路径仍保留原触点兼容语义，不能把其固定末端标记视为独立接触证明。二维床不进行旧平床粗化，预算不足如实停止。法向力为末内部步实际冲量除以该步长；高EA放缆瞬态张力和冲击峰值须另验步长收敛，残差通过不认证工程载荷。完整限制见 `BATHYMETRY_NOTES.md` 与 [INITIAL_EQUILIBRIUM_NOTES.md](INITIAL_EQUILIBRIUM_NOTES.md)。

### 9.5 坡床悬垂与变深定端静力

打开“坡床 / 变深静力”，上传真实 `oceanroute.bathymetry.v1` 床格，或明确载入标为合成的例子。网格X/Y是局部米制轴，z相对模型海面0向上；完整已知双线性单元才能查询，出域和缺测不外推。来源标签不自动完成垂直基准转换。

“坡床悬垂”要求全域仿射平面、均匀正湿重、EA和触点总张力B。填写船端位置及触点→船端水平航向，0°北、90°东。B不是水平张力H；沿向坡度m下 `H=B/sqrt(1+m²)`。只有明确选择不可伸长，才使用EA无限大极限。检查实际触点、自然材料长、伸长弧长、离散直段长、端力、切向/根残差及床格不穿透。触点牵引是输入边界，不包含海底尾缆摩擦和锚位置。

“变深定端”另要求两个固定端位置、正有限EA，以及总自然长度或每段正自然长。可使用任意合法双线性床，选择无摩擦自由接触，或明确声明床上内节点粘着位置和非负摩擦系数。固定锚端可以离床，它不是自动求得的触地点。端反力包括半段节点湿重，不能与首末缆段张力混同。

查看逐段张力、实际法向力、可用摩擦、所需粘着力、力残差和完整直段最小clearance。粘着模式只检验声明位置的摩擦容量，不能推断加载历史；所需力超容量时，实际摩擦截断并公开残力，结果不通过。优化收敛与 `accepted` 分开显示；段内穿床、残力失败、预算耗尽等候选不可用，即使节点看似贴床也不会标为通过。

参数改变后旧形状和下载失效，本页不修改制造库存或自动生成checkpoint。在“变深定端”的当前无摩擦候选通过独立验收后，可点击“用此定端输入预备同质无流动态”。它显式切入同质、EI=0、零流、零初始速度及零船速/放缆的动态草稿，保留原端点、自然长和完整床格，并清除旧混材、实体、船令、剖面及恢复草稿。**静力节点只作为数值初值**；动态运行按更严格容限重新求解和验收，不把静力 `accepted` 或显示节点改名为恢复状态。需要后续运动时再明确设置允许的命令。

静力模型本身不含海流、抗弯/扭转、混合材料、有限体、土体或运动边界；通过仅表示声明模型的数值验收通过，不证明唯一或加载可达。详见 `STATIC_BATHYMETRY_NOTES.md` 和9.7。

### 9.6 四种边界悬链线 Calculator

在顶栏“敷设仿真”中打开“悬链线 Calculator”。明确填写每自然米湿重、EA或不可伸长、船端位置与触点→船端航向，并上传完整仿射床格。也可以填写船端正下方床面相对海面z=0的深度、沿向/横向坡度百分比和有限X/Y边界，点击“明确生成有限仿射床格”。该深度不是船端Z到床的距离；沿向朝触点→船，横向朝船向右侧，正坡表示床高上升，造格节点须低于海面。这个操作建立用户声明的平面，不代表实测地形，坡度10表示10%，不是10°。修改平面参数后须重新生成床格。

选择一种已知边界，填写原始值，其他边界由真实求解得到：

| 已知量 | 单位与含义 | 必须明确的约定 |
|---|---|---|
| 底部总张力B | N，触点合力幅值 | 不等于水平张力H |
| 顶部总张力T | N，船端缆张力幅值 | 不用垂向力代替 |
| 顶部角 | degree，相对水平、有符号 | 沿触点→船端，必须大于床面切线角且小于90° |
| 入水缆长 | m | 选择自然材料长或弹性伸长弧长；离散折线长不能代替 |

输入只能有一种边界。有限EA下，两种入水长度会给出不同边界方程，必须选择基准；不可伸长极限才相同。换算按钮采用所选解的未舍入值，不能把显示的舍入数字当成精确回算输入。

下坡可能存在两个数学根。默认要求唯一根；“仅枚举”只提供候选，“低B根”或“高B根”是明确的分支选择。候选逐一显示总底张力、顶张力、自然长、伸长弧长、水平角及拒绝原因。完整枚举、声明长度域内根数和原床格验收通过的可用根数分开报告。低/高策略不会在所选根失败时自动换另一个根。没有已选定可用解时不画可用缆形，可下载明确标注未验收的诊断。

每个候选重新通过原床格覆盖、海面、切向、力平衡及边界残差检查；缺测或域外不能通过投影位置补救。张力搜索域为B=1e-6至1e9 N，自然长度另有用户声明上限，可展开“真实求解预算与长度边界”设置。算法按已证明的单调/单峰分支括根，不把粗扫描遗漏的根当成不存在。工作/输出预检超限返回HTTP422；运行内迭代或评估预算耗尽，或临界峰值附近无法分辨一根、双根或无根时，返回有限拒绝诊断并显示“根数未分辨”，不允许选择局部已求得候选。

随附2000m平床不可伸长例来自公开手册的单一图例：w=17 N/m、B=34000 N，得到T=68000 N、60°、自然长约3464.101615 m及layback约2633.915794 m。它与截图舍入值和独立平床公式一致，不能证明原厂全部算法等效。另有有限EA及下坡双根合成例，均须明确点击载入。参数、床格或分支策略改变后旧形状和下载失效，重新求解。

此模型只求均匀正湿重、无流、仿射床面切向触点的柔性悬空段，不含海底尾缆摩擦、弯曲、实体、加载历史、稳定性或海试验证；不会自动应用到规划装配、动态初态或checkpoint。完整API及数学审核见 `CATENARY_CALCULATOR_NOTES.md` 与 `CATENARY_INDEPENDENT_REVIEW.md`。

### 9.7 明确定端动态初态与完整恢复

在“敷设仿真 → 缆形与悬空段求解 → 动态敷设”展开“动态初态来源”。“原水平悬链线 / 床面投影近似”保留原行为；选择“明确定端自然长 · 实际平衡求解”才启用新初态，不从规划路线、显示形状或默认水深猜边界。

首次使用可点击“加载明确合成定端平衡动态算例”。这个按钮载入明确的研究输入，不能当作现场测量。自己的数据按以下流程填写：

1. 在“分层海流与变化海床 → 二维床面网格 JSON”载入完整床格。X东/Y北/Z上，以米计，海面0已对齐；来源标签不完成水平或垂直变换。船端、固定端和所有节点须使用同一局部坐标，不能把WGS84或绝对投影E/N直接当作局部米。
2. 在“明确动态定端初态 JSON”填写原始边界和自然库存。总自然长与每段自然长二选一；节点数由主参数决定，6–80个，每段不少于0.0001m，总自然长不超过1,000,000m。逐段数组顺序为船→固定最老端，必须为nodes−1项。可选初始节点位置只是迭代种子，不能附 `accepted` 或用完整静力结果代替原始对象。
3. 核对真实已解析物性和初始载荷。初始活动自然区间要求相同正湿重w、相同正有限EA、EI=0、无已部署实体、无初始波浪载荷；恒定海流及每条 `current_profile` 样本均须为0，不能只检查节点所在深度。不同干质量、直径和阻力参数可保留；尚未放出的不同缆材、EI或实体可作为未来动态配置，不表示其初始非均匀平衡已实现。
4. 点击“预备并独立验证动态初态”，核对自然库存、材料原点、最大节点净力残差、力容限、迭代和初始化额度。完整直段也检查床面覆盖和穿透，不仅看节点。优化器终止不替代独立力/材料/几何验收。
5. 点击“运行计算”。实际动力从相同原始边界再次求解验收后积分，预备成功不能免检。初始节点速度为零，船速、放缆和允许的后续运动从真实内部步施加；这不是有初始航速的移动铺设准稳态。输入更改后旧证据、形状和下载失效，迟到响应不回写。

初态字段示例仅表示原始边界，须配套上述完整床格和主配置：

```json
{"schema":"oceanroute.dynamic.initial-equilibrium.v1","vessel_position_m":[0,0,0],"anchor_position_m":[-15,0,-10],"natural_length_m":20}
```

固定最老端可以在床上或离床，船端可以在海面或水下，但都不得穿床。节点材料坐标从 `initial_suspended_material_m + L` 向最老端递减，初始L不计入本次新放缆；没有初始双投库存。无实际床接触时，`touchdown` 和 `bottom_tension_n` 为null，界面显示不适用，不补零或标假触点。固定支持点灰色显示，`anchor_segment_tension_n` 是锚端末段张力；端反力含半段湿重，不能与缆段张力混同。

新路径采用预应力v4研究积分，真实施加力对应的位置修正后继续约束、接触、速度和摩擦计算，没有冻结自由节点。初始接触取无切向静力支持，不推断粘着历史；动态摩擦可声明0–2。主动态原12M归一化额度不扩大；初始化另有明确预算，默认200M、最多2B，可在原始初态的 `solver` 中声明。昂贵求解前先检查工作及容量，超限或无可用平衡明确拒绝。额度不是CPU时长、FLOPs或token费用，初态通过不保证冲击、高EA、粗网格和长航程载荷精度。

保存完整动态状态后恢复使用真实位置、速度、自然段、材料、床格和原始初态证据，不重跑静力优化、不从最后显示帧反猜。新定端路径为 `oceanroute.dynamic.checkpoint` schema3 / model-v4；旧schema1/model-v2、schema2/model-v3按原方案恢复，不自动升级或删证据降级。只有允许的未来控制可修改，物性、锚、床格和数值设置保持冻结。voyage首块只重求一次初态，后续块复核保存proof而不重复初始化；每次恢复的proof检查仍占实际预算。

文件入口须区分：

| 文件/对象 | 正确用途 |
|---|---|
| 完整工程schema2 JSON | 顶层导入/保存整个工作区，不是动态状态 |
| 动态API请求 `{config}` 或 `{project,config}` | 向动态API提交；界面按主参数、床格和 `initial_equilibrium` 分别填入，不粘贴到恢复入口 |
| 计划预备请求 `{project,config}` | 按9.3生成并审查窗口，返回配置保留 `plan_mapping` 再建任务，不是恢复文件 |
| 动态checkpoint schema3 | “动态状态保存与续算”中的完整动态状态；含原始平衡证据 |
| voyage checkpoint外层schema1 | “从完整长时状态文件继续”；其物理子状态可为schema3，不与普通动态恢复文件互换 |

[initial-equilibrium-dynamic.json](../examples/initial-equilibrium-dynamic.json) 与9.3的地理例均为已实际API执行的完整**合成请求**，不是现场测深或checkpoint。初始化合同与独立验证见 [INITIAL_EQUILIBRIUM_NOTES.md](INITIAL_EQUILIBRIUM_NOTES.md)、[EQUILIBRIUM_INITIAL_REVIEW.md](EQUILIBRIUM_INITIAL_REVIEW.md)；界面任务关联与迟到响应审查见 [PHYSICS_UI_INDEPENDENT_REVIEW.md](PHYSICS_UI_INDEPENDENT_REVIEW.md)。

## 10. 导出与故障处理

导出 RPL CSV、KML、GeoJSON、局部米制 DXF、SLD SVG、可打印 HTML 报告、完整 JSON 和制造装配 CSV。HTML 可用浏览器打印 PDF。普通图形/清单导出针对活跃路径，完整 JSON 导出整个 schema 2 工作区。DXF 用于图形交换，不含完整工程语义；完整往返用 OceanRoute JSON，不能改后缀冒充原生格式。

规划中“—”检查地形缺测、剖面失效、范围或零長段；新明确定端动态路径无实际触地点时，底张力“—”表示不适用，不是零张力，也不必然是测深缺失。导入失败检查列名/单位/坐标/缆型；投影失败检查CRS、原生单位、覆盖域、最佳基准网格及当前制造域。动态警告检查物性、原始边界、内部步长和网格收敛；无可用初态须修正实际输入，不用旧结果继续。启动失败检查 Python、依赖安装和端口。保留完整工程、配置、版本和结果以复现偏差。

原厂专有文件、船载接口和完整维修专项尚未兼容；完整范围见 `IMPLEMENTATION_STATUS.md`。Token 费用由平台结算，助手不能接受转账。
