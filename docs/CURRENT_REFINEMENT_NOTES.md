## 对照问题及其范围

共同声明为自然库存24m、制造原点37m、固定最老端(0,0,−30)m、施加于该端的朝船牵引(150,10,35)N和水平流(0.32,−0.27,0)m/s。两种材料的w/EA/Cd/直径分别为4N/m、10000N、1.1、0.02m与7N/m、24000N、1.4、0.025m。点实体湿重取+30N和−30N，阻力面积0.02m²、Cd=1.2。明确床格为z=−100m，全部缆均离床；不是将未知曲床展平。

四组分别为材料边界/point自然站与网格对齐的8m/14m，以及不对齐的8.3m/14.7m，各配正/负point湿重；每组取12、24、48个自然元素。所有元素保持实际自然库存、混材柔度、缆/point质量与净湿重，不移动材料边界、不把点硬塞到节点。

**这是共同端牵引与自然库存的细化实验。** 每个离散网格都从独立力平衡构造自己的船端坐标，然后把这两个真实端点交给产品；不同网格的船端不同。它不构成共同定端BVP，也不证明曲床接触或剪切流的网格收敛。后者的节点/全弦/恢复验收见 [流初态独立报告](CURRENT_INITIAL_INDEPENDENT_REVIEW.md)。

## 连续参考与离散参考相互独立

连续自然坐标s从最老端增向船端，f为该方向的真实牵引，t=f/|f|。各材料段内使用独立DOP853积分：

```text
dp/ds = (1+|f|/EA)*t
df/ds = w*e_z - (rho/2)*Cd*d*|P*U|*(P*U)
P = I-t*t^T
```

材料分界处位置与牵引连续；在point站处位置连续，施加真正跳变

```text
f_after-f_before = B*e_z - (rho/2)*Cd_body*area*|U|*U
```

B可负。不能遗漏body水平拖曳，也不能把EA伸长误作自然库存。积分容限rtol=1e−11、atol=1e−12、最大自然步0.25m；另独立用无流闭式分段弹性积分核对符号、伸长量与正/负point跳变，并进一步收紧积分容限校核参考差异。这些无流检查只验证参考积分器，不代替真实非零流12组运行。

离散参考在牵引变量中求解非线性力递推；预期材料积分/串联柔度、半总量载荷、自然point系数均用60位Decimal区间交集独立形成，不导入被测水动力或材料helper。节点切向使用与声明模型相同的索引secant，cable normal drag与node-lumped isotropic point drag直接计算。

端点半缆载荷不能遗漏。最老元素牵引f_last必须满足

```text
f_last + D_anchor - W_anchor*e_z = applied_bottom_traction
```

不能简单令f_last等于外部施加牵引，否则会产生随网格变化的端点重力/拖曳偏差。实际proof的最老端反力均独立核对为−(150,10,35)N，船端反力独立与离散递推核对，再比较连续顶部牵引。

每个参考真正进入raw initial-equilibrium.v2、provenance.v3、model-v5与checkpoint schema4；重新求解并核对实际首帧材料、质量、湿重、EA、端反力及自由节点力。随后实际积分一个2ms内部步，保留paid=0与24m原库存，不把参考节点当免检恢复档案。

## 实际驱动时间探测

同一24段不对齐/−30N网格，真实船速0.2m/s、放缆0.25m/s，运行0.08s。内部步0.016、0.008、0.004、0.002s分别实际执行；当前允许的最小2ms作为数值参考，不作为精确动力学真值。

前三者相对2ms的最大位置差分别约0.5580、0.3044、0.1451mm。各次自由节点实际移动约9.257—9.307mm，新增放缆均0.02m，总自然量24.02m；固定最老端未移动。这验证真实驱动响应与库存守恒，不称加载历史重建、现场误差界限或普遍时间收敛阶。更独立的动态ODE时间对照由主任务另行记录，不能与本最细步比较混称。
