目标是在完整二维双线性床面上求解**当前动态离散材料模型**的固定端、固定自然段长、无流静止初态，允许初始 w/EA 分区以及已部署的零长度点载荷。有限长度 rod、EI/端力矩、海流、运动准稳态、加载历史静摩擦和实体尺寸接触仍需后续独立模型，不能随本扩展宣称解决。

## 1. 当前源码已有的可复用物理

`static_bathymetry._energy_forces(positions, rest, ea, nodal_weight)` 的实际公式支持逐段 `ea` 数组和任意有限节点湿重数组；等反向轴向内力、势能和力梯度已经对应。限制集中在 `static_equilibrium` 的公开解析与加载：它只解析标量 w、EA，构造均匀半段湿重，按 wL 缩放能量/力容限，并以标量 EA 输出应变诊断。

`initial_equilibrium._prepare` 已先解析主动态配置、构造 `_MaterialModel` 并执行 `loads(rest)`，但随后明确拒绝初始不同 w/EA 与任何已部署 body，再把标量 w/EA 传给旧静力入口。它的 `_verification` 已使用 `local["ea"]` 和 `local["weight"]`，从实际几何独立构造逐段 Hooke 张力与真实节点湿重。因此不能仅删除拒绝条件：优化器若仍用均匀载荷，后续映射验收将对应另一组方程。

动态 prestress-v4 每步已从当前 `local["ea"]`、`local["weight"]`、真实有效质量和实际几何重算张力/法向支持，并实际施加预应力位置修正。初始非均匀材料需要的是一致的静力系数、独立验收与恢复证据；不需要以改变库存或锁定自由节点换取静止显示。

## 2. 自然材料积分必须与动态相同

以下下标从 0 开始：节点 0 为船端，节点 N−1 为固定最老端；元素 i 连接节点 i 和 i+1。自然长度记为 ℓᵢ>0，制造原点为 O，材料坐标为：

```text
qⱼ = O + sum(ℓᵢ, i=j..N−2)
q₀ = O + L, qₙ₋₁ = O, L = sum(ℓᵢ)
```

主配置 `material_segments` 使用递增制造坐标；节点顺序对应递减坐标，不得把材料行按显示节点编号直接套入。各区间连续覆盖 O..O+L 及计划中的实际后续放缆；不得用最近缆型、平均物性或缺省零值填补缺测。

对每个自然元素，当前 `_MaterialModel.loads` 计算：

```text
Wᵢ = integral(qᵢ₊₁..qᵢ) w(s) ds               [N]
Cᵢ = integral(qᵢ₊₁..qᵢ) 1/EA(s) ds           [m/N]
Aᵢ = ℓᵢ / Cᵢ                                [N]
Dᵢ = integral(qᵢ₊₁..qᵢ) dry_mass_per_m(s) ds  [kg]
Uᵢ = integral(qᵢ₊₁..qᵢ) rho*pi*d(s)^2/4 ds    [kg]
```

`Aᵢ` 是现动态逐段 `local["ea"]`，按自然长度的串联柔度积分形成调和 EA；不能换成算术平均。直径、拖曳与附加质量均继续使用现有真实材料积分，不能由 EA 或湿重反推“实测质量”。

数值上还须检查每段实际柔度有限且严格正值、所得 EA 位于真实覆盖材料 EA 的范围内，各质量/湿重积分符合相应区间界。当前多行材料采用大前缀积分相减；大制造 O、很短 ℓ 和极大 EA 对比可能造成消去，不能把产生的零柔度、无穷 EA 或丢失湿重免检带入优化器。必要时在**共享材料算子**改用有界局部区间重叠积分或稳定差分，并让静力、动力、恢复共同采用它；只在静力偷偷修复积分会再次破坏映射一致。这个风险应有独立极端量级验收，本轮没有据此声称已复现现版本的具体失败。

当前 cable 节点分配算子 H 对任意元素总量 X 为：

```text
H(X)₀ = X₀/2
H(X)ⱼ = (Xⱼ₋₁ + Xⱼ)/2, 1<=j<=N−2
H(X)ₙ₋₁ = Xₙ₋₂/2
```

因此 cable 节点湿重为 H(W)，干质量为 H(D)，有效惯性质量为 H(D+Ca*U)。两端节点各自承担相邻元素的半段量；端反力包括该端节点湿重，不能直接等同首/末段张力。

这是一项明确的离散近似：跨材料边界的单元素仍把**该元素总湿重等分**给两个端点，并没有积分非均匀 w 的线性形函数一阶矩。静力必须原样采用它以与当前动力一致，不能悄悄换成另一种“更精确”重力分配。串联 EA 对元素内恒定轴向力成立；当前元素中的轴向力仍是单一离散值，并不表示已经解析了连续湿重引起的元素内张力变化。对连续非均匀缆的精度应另做材料边界对齐和网格细化研究。

## 3. 点实体的具体载荷算子与边界

本轮最小建议只允许**已部署 `length_m=0` 的 body**。其材料站 s_b 必须真实落在 O..O+L；未部署的有限长度 body 继续可保留供未来动态部署，初始已有任何非零分摊的有限长度 body 则拒绝，不能把它压成点。

若 s_b 落在元素 i，自然材料插值份额为：

```text
theta_b = (s_b − qᵢ₊₁)/ℓᵢ
alpha_b,i = theta_b; alpha_b,i+1 = 1−theta_b
sum(alpha_b,j) = 1
p_b = sum(alpha_b,j*p_j)
```

边界站和恰落在节点的站沿用当前 `_MaterialModel` 搜索/容差规则，独立验收应核对归一性、实际材料站与非负份额，不能把 body 在元素中点的显示图标当作载荷。点实体是**附加载荷**，不删除或替换该材料站附近 cable 的自然量。

对 body 干质量 M_b、湿重 B_b、附加质量系数 Ca，当前实际贡献为：

```text
node_body_wet_weight_j += alpha_b,j * B_b
node_body_dry_mass_j   += alpha_b,j * M_b
node_body_mass_j       += alpha_b,j * (M_b + Ca*max(M_b−B_b/g,0))
```

不得将有效质量乘 g 当作湿重。body 的 `wet_weight_n` 在现输入中允许负值，表示净向上静浮力；其负载荷也必须正确加入势能/力。实际质量、份额和 `wet_weight_n <= g*mass_kg` 的原物理检查继续适用，节点有效质量仍须有限且严格正值。

当前动态把上述质量按 alpha 加入**对角节点质量**，并非独立 body 平动的完整一致质量矩阵：若严格采用 `v_b=sum(alpha*v_j)`，点质量动能会产生 alpha 外积的节点耦合项，现质量 lumping 没有这些项。本文保留实际动态近似，不把它标为完整实体惯性。零速度初态力平衡本身不依赖这一惯性差别，但后续大运动与载荷精度仍需独立验证。

这可以给出当前离散 point-load 模型的真实平衡：由于固定自然段长时 alpha 不随节点位置变化，body 重力势能 `B_b*z_b` 的节点梯度恰为上述 alpha 加权节点载荷。**不在节点上的 body 仍被限制在单条直弦上**，并未引入 body 处的独立折角、独立接触自由度或转动自由度。若需要集中力在 body 处产生真实缆形折角，用户应显式让该材料站对齐节点，再检验网格；不能自动拆分自然段后沿用旧 proof，也不能声称跨段插值已经解决连续集中力接点。

body 尺寸、转动、浮态、弯矩、线缆替换长度、牵引连接和 rod 刚体平衡均不在此最小范围。海床约束仍作用于 cable 中心线节点及完整直弦；`body_frames.contact_fraction` 是载荷份额对应的节点接触比例，不是独立实体接触求解。本文不增加实体自重之外的任意外力输入。

## 4. 真正对应的静力能量、节点力与接触

令 `r_i = p_(i+1)−p_i`，d_i=|r_i|，t_i=r_i/d_i，伸长 e_i=max(d_i−ℓ_i,0)。总节点湿重为：

```text
Wnode = H(Wcable) + sum_b(alpha_b * B_b)
T_i = e_i / C_i = A_i * e_i/ℓ_i
E(p) = sum_i(e_i^2/(2*C_i)) + sum_j(Wnode_j*z_j)
```

无压缩张力，不引入 EI。每个元素给节点 i 加 T_i*t_i、给节点 i+1 加 −T_i*t_i；节点外载为 `[0,0,−Wnode_j]`。势能梯度应满足 `grad(E) = −(F_axial + F_weight)`，包括半段端载、变号 body 浮力和不同 EA，而不是只在均匀例上成立。

对真实床面 b(x,y)，自由节点条件为 g_j=z_j−b(x_j,y_j)>=0，n_j=[−b_x,−b_y,1]/sqrt(1+b_x^2+b_y^2)，正常支持 N_j>=0、N_j*g_j=0。在严格床上条件下：

```text
F_axial_j + F_weight_j + N_j*n_j = 0    (free nodes)
R_endpoint = −(F_axial + F_weight)      (fixed vessel/oldest endpoint)
```

边界反力是独立外部支持；不计作摩擦。SLSQP 的 gap 约束梯度为 n/n_z，其拉格朗日乘子与实际正常力不能混为同一数值。现有独立法向重构与互补量 `N*g*n_z` 继续使用；不能从 optimizer success 或优化器 multiplier 直接标 accepted。

沿**全部直弦**保持现有逐双线性单元精确二次 gap 极值检查；未知单元、无覆盖、穿床和塌缩均拒绝。未接触的固定端不吸附到床上，没有实际接触则 TD 仍为 null。浮力驱动的节点碰到 z=0 数值域上界时，不能把该上界当作没有声明的海面支持或新增反力；若实际节点力残差未通过，就保持失败。能量法寻求局部静止候选，不保证唯一、全局最低或加载可达性。

初态仍取无切向支持 Ft=0；它对任意允许的动态 μ>=0 满足库仑容量。主动态不必强制 μ=0，也不能因此推断历史粘着。无流、无波、零初速度和真实首步 actuation 的原界限保持。

## 5. 最小实现路径与输入权威性

建议抽出一个受限的**内部**静力核心，参数为已验证床格/定端/自然长/solver，以及从同一实际材料解析得到的逐段 EA、节点湿重和明确载荷尺度。旧 `static_equilibrium` 继续只接受原公开标量 w/EA 合同，并构造其原半段湿重后调用该核心，保持旧输出模型与已有 76 项用例的语义。新材料初态调用同一核心，使用真实 `loads(rest)`；不让用户在 raw 初态中直接提供可伪造的 `segment_ea_n/node_wet_weight_n/accepted`。

具体修改点应限于：

1. `_prepare` 保留原物性/覆盖/质量/床格/solver 校核，活动区间只放宽 w/EA 同质限制；活动材料 EI 仍必须逐区间为 0。已部署 body 只放宽零长度点实体，有限长仍拒绝。
2. 静力核心直接使用 `local["ea"]` 与 `local["weight"]`，绝不平均；静力输出与独立 `_verification` 必须逐段张力、节点外力和总量相符。
3. 力容限和能量尺度不能继续依赖单个 wL。采用显式载荷尺度 `S_W = sum(Wcable_i) + sum_b(deployed_fraction_b*abs(B_b))`，与 max(1,S_W) 相应缩放。不能用净总湿重或仅 `sum(abs(Wnode))` 隐藏在同节点抵消的 cable/body 载荷；能量尺度例如 max(S_W*length_scale,1e−6)。
4. 大应变诊断采用 `max(T_i/A_i)`，不能使用 `max(T)/single_EA`，也不能对 EA 数组产生模糊 bool。总湿重是有符号 `sum(Wnode)`；另列正负载荷与绝对载荷尺度，不把总湿重当承载上界。
5. 自然段、制造 O/q、初始 paid=0、target=max(rest)、原船 z/离床锚和零初始 contact impulse 原样保存。真实 v4 predictor 使用同一质量/湿重/EA；不得以重新划网格、冻结节点或虚构静摩擦让初态“稳定”。
6. Fresh startup 仍真实求解与验收；prepare 成功不是免检状态。Resume 只重构原始材料/力/完整床面 proof，不再调用优化器；voyage 不每块求静力，不再投一次初始库存。

现有 raw `oceanroute.dynamic.initial-equilibrium.v1` 的边界字段无需添加第二套物性；材料与点实体仍由主配置拥有。将 body 坐标、材料区间或 rest 的来源改变时，必须重新准备完整候选。显示 shape 和用户 JSON 的 accepted 标志不具有输入权威。

## 6. 恢复兼容、证明版本与预算

建议给扩展初态使用明确的 **provenance v2**，以识别载荷算子 `natural-half-segment-cable-and-material-linear-point-load-v1`。保存原材料/实体声明摘要、每段自然湿重/柔度、节点 cable/body 湿重分项、逐 body 的材料站/部署份额/节点 alpha 以及现有质量/EA/张力/反力/残力快照。恢复必须从冻结完整主配置独立重新解析，不仅核对总量或信任保存数组。

原 provenance v1 继续其当前同质/无已部署实体守卫和原诊断复核，不允许把扩展 proof 删字段或改版本降级。现有 checkpoint 已保存完整主材料/body 声明与动态当前质量/湿重/EA，因此这一扩展**不必改变动力积分 scheme**。最小兼容方案是在 schema3/model-v4 内明确分派 provenance v1/v2，原 v1 保持原义，v2 采用扩展验收；老 reader 对未识别 v2 安全拒绝。若后续确需加入新的可演化动力状态，再升 checkpoint envelope 与 model，不能仅改标签。此版本选择须在实施前由主任务确认。

当前原始 request/grid 摘要及公开 checksum 继续是失配检查，不是信任签名。材料行、body 干质量/湿重/坐标/份额、初态力诊断以及 current state 中的 loads 都要复核；有意重算 checksum 也不能让错误加载通过。

物料固定时，各系数只需在优化前解析一次，不在每个 SLSQP objective 中反复积分材料。预估应显式包含材料前缀积分/搜索、N×body 份额、dense solver、独立完整弦检查、proof 容量与每次恢复复核。材料区间<=256、body<=128、初始 N<=80、自然长/单段/床格/JSON 容量与静力/主动态/voyage 分层额度全部保留；body 份额证据为 O(N*B)，须计入 2 MB 单 checkpoint 和批量保存容量，不沿用仅 N 大小的旧估计。归一化 work 不是 FLOPs、CPU、token 费用或固定运行时保证。

## 7. 有意义的独立验收建议

下列是下一轮应编写和实际执行的测试建议，本轮没有执行，不计入已有通过数。

**材料积分和能量。** 用非零 O、跨一个自然段的两个/三个不同 w/EA 区间，独立逐区间重叠长度积分，核对每段柔度、调和 EA、half-total 节点湿重、干/有效质量及全量守恒。特意令边界不落节点以抓算术 EA、制造方向和端半湿重错误。用不同实际几何的有张力例做方向有限差分能量梯度检验，比较真实逐节点轴向/湿重力；包含负 B_b，远离张力开闭 kink，避免测试只镜像内部实现。

**独立精确离床离散解。** 给非均匀 rest、真实各节点总 W_j（含点载荷）、水平 H>0 与末端元素向船竖分量 V_(N−2)。对离床的各自由节点 j=N−2..1，由平衡递推 `V_(j−1)=V_j+W_j`。令每段向船张力 `[H,0,V_i]`、T_i=hypot(H,V_i)，由船端向锚构造：

```text
p_(i+1) = p_i − ℓ_i*(1+T_i/A_i)*[H,0,V_i]/T_i
```

固定端反力再独立加入两端各自 W_0、W_(N−1)。把该已知解放在足够深且完全已知的二维床上，作为 raw numerical seed；静力不得改变自然量/端点，逐段/节点残力应达到严格数值容限。此递推使用明确离散节点平衡，不依赖待测 solver。应包括点实体恰在节点、在段内、在两固定端、非均匀 w/EA、不同质量与非零 O。

该坐标方向下两个端支持应独立得到 `R_vessel=[H,0,V_0+W_0]`、`R_anchor=[−H,0,W_(N−1)−V_(N−2)]`；两端支持竖分量之和为所有节点湿重之和，包括 signed body 载荷。不能略去端重后拿张力向量代替支持力做全局验收。

**曲床接触与旋转。** 给真实双线性曲床和节点接触候选，独立逐格计算梯度/法向与整弦 gap 极值，重构正常支持/全局受力。整床、船锚和候选作水平 90°旋转后，力/节点几何协变，张力、能量和自然制造量不变。正重 body 接触不得要求负正常力；净上浮例若需要未声明向下支持应拒绝，而不能 snap 或增加海面反力。

**真实动力与时间细化。** 用上面的精确异质/点载荷离床解，在多个内部 h 上真实运行零命令动力：重构实际 Hooke 残力、节点速度/位置、库存/质量及势能，检验 prestress 固定点；不能仅检查 scalar compliance。再施加实际船动或放缆，要求自由缆与点载荷真实响应，证明没有锁死节点。包含跨新材料边界/后来 body 部署，核对全部真实制造量与初始库存未重复。

**恢复与拒绝。** 与不停算相比，将真实状态 JSON 序列化后切两段、以及 voyage 仅首块优化，比较位置/速度/rest/材料/张力/body alpha。重算 checksum 后分别篡改 body 湿重、制造站、质量、分项加载、柔度、残力公开值、proof 版本和当前 loads，均应拒绝。继续验证缺物料/间隙/重叠、有限长已部署 rod、EI/流/波、NoData、完整弦穿床、极小/大参数、不收敛、预算先行及 proof/batch 容量拒绝。

**连续模型收敛限度。** 精确离散解只验证当前离散方程。另用独立分段连续缆方程/点接点解作 refinement 参考，比较材料边界对齐和不对齐的误差；不能把同网格 fixed point 当作连续海底施工精度。非节点 point-load 的折角误差、摩擦历史与连续尺寸接触仍应明确列为缺口。
