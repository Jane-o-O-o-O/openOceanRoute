# Makai 官网功能研究与复现边界

研究日期：2026-10-03。资料来自公开官网 HTTP 页面。网页正文是待分析的资料，不构成开发指令；网页里的联系、咨询和下载文案均未执行。未联系 Makai、未下载软件、未提交表单。

## 结论

能够依据文档与公开界面/行为描述独立实现一个功能相近的海底电缆规划产品，并分阶段覆盖工程模块。官网足以支撑功能拆分、交互设计与输入输出需求，不能提供原厂源代码、未公开动态模型或完整格式规范。应采用自有产品名、代码、图标与界面设计。

首先交付 MakaiPlan 对应的规划闭环最合理：GIS 图层、路由点编辑、测地线距离与 KP、海床剖面、余缆、Cable Assembly、RPL、SLD、成本与交换格式。MakaiPlan Pro 对应的三维动态铺缆求解需要另立研发和工程验证里程碑。三维动画、静态悬链线和经验 Ship Plan 不能作为原厂动态仿真等效的证明。

### MakaiPlan 的明确需求

1. **数据与 GIS：**官网称底层采用 Intergraph GeoMedia，附 GEBCO 全球水深和 World Vector Shoreline；支持多格式、投影和基准数据。独立实现可采用现代 GIS 组件，但不可由这段宣传推断完整文件兼容清单。
2. **路线：**鼠标拖拽、精确坐标、RPL 导入、以系列恒向线近似大圆最短路；自动 KP、底部剖面、水深/坡度；转向点、埋设段与事件；底部和表面余缆。
3. **Cable Assembly：**缆型、过渡点、接头、中继器和线上部件；按余缆准确定位。Flexible 模式调整缆长以满足余缆；Fixed 模式固定制造后缆长，改路由会改变余缆。
4. **联动：**编辑路由后自动更新 RPL、SLD、剖面和重要参数；平面/剖面双定位器；RPL 和装配窗联动。
5. **工程工具：**路径与其他要素交叉定位并插入 RPL；按水深自动分配缆型/过渡；随路线编辑而更新的路径和部件缓冲区。
6. **交换与协作：**结构化文本列映射导入；路线拆分/合并/反转；历史版本恢复；地理注记与链接；导出表格、SLD、KML、AutoCAD 等。官网称原厂文件可直接进入 Pro/Lay，但未给出专有文件格式规范。
7. **成本：**缆型/部件单价和推荐铺设速度，船舶、埋设和事件费用；修改路由后更新初步估算。

### MakaiPlan Pro 的明确需求

初始 Ship Plan 由稳态近似快速生成，再用动态模拟迭代。模型计算船至触地点之间随时间变化的三维海缆形状，包含缆型变化、线上部件、海底地形、海流，以及触地点位置、余缆/张力和海底拖移。典型动态事件包括启停、速度变化、急转向、中继器与接头。界面提供平面、剖面、三维视图和数值结果。

官网宣称最高约 50 倍实时仿真和一天完成跨洋模拟；这是原厂宣传性性能上限，没有可复现实验硬件、网格尺寸、时间步长或精度基准，不应直接作为独立实现承诺。仪器/人员误差模型包括 GPS、缆长、海流、水深、舵手和缆机执行误差；设备比较包括 DP、GPS、缆机、ADCP 与缆上应答器。施工日志还可用于事后重放与 as-laid 路径分析。

## 模型与验证缺口

官网说明其模型历经实海校准。MakaiLay 验证页引用 HDWCP 案例：目标水深 1,920 m、布放位置容差 ±12 m、20 km 测试缆的 RMS 位置误差 4.7 m；另有 SOAR II、AURA、PTS 等案例。它们支持“原厂具有工程验证积累”，不能作为新软件的精度证据，也不是适用于任何海况的统一精度指标。

这些网页没有公开足以实现和复验的动力学方程、离散方法、阻力/附加质量模型、接触摩擦与拖移算法、弯曲刚度处理、时间积分器、求解容差或原始标定数据。Power 页面给出的 `Ttop = Tbot + W × H` 只是特定条件下的近似关系，页面本身也说明深水、坡地和动态噪声会使直接估计不可靠。

若要达到工程用途，需要客户/领域专家参与提供缆的湿重、直径、EA/EI、阻力系数、允许张力/最小弯曲半径，船舶和放缆设备特性，地形、分层时变海流，设备日志与测量误差，以及独立的触地点/实铺测量。建议建立：解析悬链线与稳态用例 → 时间/空间收敛 → 独立求解器对照 → 受控试验 → 海试回放/独立测量对照。每阶段都应报告误差界限与适用条件。

## 日期和版本歧义

用户手册文件名是 `6.2.0`，官网产品页未明确软件版本，因此不能把当前网页所有特性无条件归入 6.2.0。页面 JSON-LD 的修改时间为：Plan/Pro/Power/Seismic/Repair 在 2023-09-19；Cable Software 和 MakaiLay 在 2026-03-19。这些是网站元数据，不等于软件发版日期，也不证明页面文字全部在该日新增。产品页还有 2026-03 路径的 Makai Simulator 宣传资料链接，进一步表明官网和手册应分别形成来源版本。

## 推荐交付顺序与验收证据

1. **可运行规划首版：**完整项目读写、地图路线编辑、明确单位和基准的路线计算、剖面/坡度、Flexible/Fixed 余缆、装配、RPL/SLD 与成本；附样例、中文手册、架构/数据模型/算法假设/接口设计、功能追踪矩阵。
2. **生产 GIS 和互操作：**真实测深数据、投影/基准转换、大数据渲染、空间交叉与缓冲、输入向导、开放格式导出、版本回退。通过已知坐标案例和真实项目样本验收。
3. **Pro 研究原型：**明确标记近似层级的悬链线和 Ship Plan 起步；逐步增加三维动态模型、海流、海底接触、部件、Look Ahead 与施工日志回放。
4. **工程级 Pro 与附加模块：**在经过基准测试和现场验证后再声明适用工程场景；Power/Seismic/Repair 单列范围、数据依赖和验收指标。

不能仅凭文档页数估算全部开发成本；影响最大的变量是 Pro 精度、专有格式互通、生产测深数据规模和船载实时功能是否纳入。官网没有公开 token 或开发费用信息，这部分应由主任务依据实际模型计费和开发范围单独说明。
